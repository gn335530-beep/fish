# 22: 行情抓取 job 與 upsert

**What to build:** 提供一個可重複執行的行情抓取 job：取得官方當日交易資料，依兩份對照表正規化，換算成元／公斤後寫入行情資料，並更新抓取狀態（最後成功時間、交易日期、筆數、錯誤）。同一天重跑不產生重複列；抓取失敗不得覆蓋既有資料，商品與對話仍可運作。（規格：G-15、AC-1、AC-2）

**Blocked by:** 21（行情魚種與市場對照表）

**Status:** ready-for-agent

- [ ] 執行 job 後，行情資料有當日各市場各魚種的上下中均價與交易量，抓取狀態同步更新。
- [ ] 民國年交易日期正確轉為西元（例：1151022 → 2026-10-22）。
- [ ] 同一交易日重跑不產生重複列，只更新既有資料。
- [ ] 平均價 ≤ 0 的資料不寫入。
- [ ] 上游失敗時回報錯誤並保留既有行情，不把舊資料清空。
- [ ] 抓取狀態看得出最後成功時間、最後交易日、筆數與最後錯誤。
