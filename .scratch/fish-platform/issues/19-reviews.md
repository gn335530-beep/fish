# 19: 雙向評價

**What to build:** 成交後，買家與釣客各可在交易房評價對方一次：1–5 星、最多 3 個標籤、100 字內評語。送出後重算對方平均星等與評價數；含「臨時放鳥」時未到次數 +1，累計 3 次列入黑名單。同一人對同一筆訂單重複送出回 409。商品詳情頁顯示真實評價，不再寫死數字。（規格：G-12、B-3 評價部分、F9）

**Blocked by:** 17（同意、退回、取消與成交）

**Status:** resolved

- [x] 成交後雙方都看到評價卡，可選星等、最多 3 個標籤、輸入 100 字內評語。
- [x] 送出後對方 `rating_score` 與 `review_count` 正確更新。
- [x] 同一人對同一筆訂單重複評價回 409，不重複計分。
- [x] 含有「臨時放鳥」標籤時對方 `no_show_count` +1；累計 3 次 `is_blacklisted` 為真。
- [x] 商品詳情頁顯示真實評價數與內容，不再出現寫死數字。
- [x] 未成交的訂單不能評價。
