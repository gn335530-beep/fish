# 06: 魚種單一來源

**What to build:** 後端提供唯一的魚種清單 API；助手對話、上架流程與網頁顯示都從這份清單取資料。新增、改名或加別名只改後端一處，前端不再保留第二、第三份複本。（規格：R-9）

**Blocked by:** 無（可立即開始）

**Status:** resolved

- [x] 後端有一個可公開讀取的魚種清單端點，內容包含識別碼、名稱、別名與料理屬性。
- [x] 助手與上架流程使用該端點，不再載入自己的魚種複本。
- [x] 網頁顯示魚種時使用同一份資料。
- [x] 在後端新增一種魚後，重新載入即可在助手與網頁看到，不需改前端。
- [x] 重複的魚種資料檔已移除，沒有留下無人引用的複本。
