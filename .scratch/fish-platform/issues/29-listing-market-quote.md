# 29: 上架行情卡與售價引導

**What to build:** 非價格欄位齊了（#28）後，查該魚種在釣客縣市的行情，送出行情卡（平均價、當地縣市近 7／30 個交易日走勢、期間最高／最低、縣市或全國平均、交易日期、來源、養殖價格、參考整批金額、新鮮批發參考），再問「請問要販賣多少錢？（可回覆每台斤價格或整批價格）」；若使用者已提供售價，行情卡後不再問，直接顯示草稿／確認發布。未知魚種不呼叫行情 API，直接顯示暫無。查無或上游失敗仍讓使用者繼續定價，不擋上架。法規確認卡由 #34 另外接在流程前面，本票不實作。（規格：G-19、AC-10、F2 步驟 4–5、02 §8.5、06 §3.2）

**Blocked by:** 23、24、28

**Status:** ready-for-human

- [x] 非價格欄位齊了 → 行情卡含平均價、7／30 個交易日走勢、期間最高／最低（由 history 計算）、縣市或全國平均、交易日期、來源、養殖價格（若）、依重量試算的參考整批、新鮮批發參考；資料含 `weight_kg`、`weight_taijin`、`estimated_total`、`history`，`estimated_total` 標「參考」。
- [x] 若尚未提供售價，卡片後問「請問要販賣多少錢？（可回覆每台斤價格或整批價格）」；若已提供售價，不再問，直接顯示草稿／確認發布。
- [x] `is_aquaculture: true` 時行情卡標「養殖價格」。
- [x] 未知魚種（`species_id = null`）不呼叫行情 API，直接顯示「暫無行情」，仍可繼續定價與發布。
- [x] 查無行情 → 「目前沒有花枝的行情。」；上游失敗 → 「暫時無法取得花枝的行情。」；若尚未提供售價，再接「請問要販賣多少錢？」；都不得編造數字。
- [x] 行情卡走勢用 `include=history&days=7|30`；`days` 是最近 N 個交易日（見 #23）；預設 7，可切 30。
- [x] 卡片在手機與桌機都不破版；7／30 切換可用（06-ui 的「無動作按鈕」同步為可切換走勢）。
- [x] 不覆寫未知的 context 欄位；未來 #34 的 `pending_sale_text`／`awaiting_consent` 不被清掉。
- [x] 測試、02／03／04／05／06／07 同步；新增前端檔案 ≤ 200 行。
