# 23: 行情查詢 API

**What to build:** 提供行情查詢：依魚種與縣市找最近交易日的行情，找不到縣市資料時退回同日全國平均，再找不到時退回該魚種最近一次有資料的交易日；回傳一律附交易日期、來源與品質標記。公斤價格換算為元／台斤（× 0.6）。查無資料回 `found: false`，不回 0 或示意值。（規格：G-16、AC-3～AC-6）

**Blocked by:** 22（行情抓取 job 與 upsert）

**Status:** ready-for-agent

- [ ] 縣市有資料時回 `scope = city`，價格以元／台斤呈現，換算正確（例：1237 元／公斤 → 742 元／台斤）。
- [ ] 縣市無資料但全國有資料時回 `scope = national`，並標示「全國平均」。
- [ ] 當日無資料時退回該魚種最近交易日，並回傳該日期。
- [ ] 完全沒有行情時回 `found: false` 與原因，價格欄位不得出現數字。
- [ ] 查詢結果包含交易日期、來源與 `quality`。
- [ ] 無效魚種或日期格式回 400。
