# 36: 助手批次回覆以第一則為滾動錨點

**What to build:** 助手一次回多則訊息（例如行情卡＋說明＋草稿卡）時，不要把聊天室直接跳到最底部，否則前面的訊息容易錯過。改成以這批的第一則為錨點：整批從第一則到最底部放得進面板時仍滾到底部；放不進時把第一則對齊面板頂端。使用者自己送出訊息、照片、發布成功與切換房間仍滾到底部。（規格：06 §6）

**Blocked by:** 無

**Status:** ready-for-agent

- [x] 訊息節點帶 `data-seq`，可定位到指定訊息。
- [x] 面板提供批次滾動：整批放得下 → 滾到底；放不下 → 第一則對齊頂端。
- [x] `runReplies` 以建立的第一則 seq 呼叫批次滾動，不再強制跳到底部。
- [x] 清除歷史後只留新訊息時，仍以第一則為錨點。
- [x] 使用者送出訊息、照片、發布成功、切換房間維持滾到底部。
- [x] 測試與 06-ui 互動規則同步；檔案 ≤ 200 行。
