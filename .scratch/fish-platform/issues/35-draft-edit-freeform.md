# 35: 草稿改為自由文字修改、取消上架後開新對話

**What to build:** 草稿卡拿掉六個欄位小按鈕，只留「確認上架／修改草稿／取消上架」。按「修改草稿」後助手以文字問「你想修改哪一項？（魚種、總重、尾數、處理方式、照片、售價）」。使用者可只說欄位再回新值，也可一句話同時說「重量改成 10 公斤」直接更新；一次只套用一個欄位。改魚種或重量後照舊重查行情、重算自動整批價；中途說「取消」只取消本次修改。取消上架確認後刪除目前助手房，直接建立並開啟一間新的助手房（含招呼語），不跳回收件匣；建立新房失敗時顯示錯誤，不停在已刪除的房間。草稿卡的「確認發布」一併改名為「確認上架」。（規格：G-22、AC-12、F2 步驟 6–10、06 §3.2）

**Blocked by:** 無

**Status:** ready-for-agent

- [x] 草稿卡沒有 `edit-slot` 按鈕與「修改」列，只留「確認上架／修改草稿／取消上架」。
- [x] 按「修改草稿」後助手用文字問欄位，列出魚種、總重、尾數、處理方式、照片、售價。
- [x] 只說欄位（例如「重量」）→ 助手問新值。
- [x] 一句話含欄位與新值（例如「重量改成 10 公斤」「處理方式改成活體」「售價改成每台斤 250」）→ 直接更新該欄位。
- [x] 一句話講多個欄位時只套用第一個，其餘欄位不變。
- [x] 改魚種／重量會重查行情；每台斤自動計算的整批價會重算。
- [x] 修改中說「取消」→ 回到修改前草稿；說「取消上架／取消販售／不賣了」→ 進取消確認。
- [x] 取消確認文案為「確定取消上架？此對話會刪除，並開啟新的 AI 對話。」。
- [x] 確認取消後刪除舊助手房、建立並開啟新助手房、顯示「已取消上架」toast。
- [x] 建立新房失敗時顯示錯誤，不停在已刪除的房間。
