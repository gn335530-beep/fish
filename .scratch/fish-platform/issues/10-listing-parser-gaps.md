# 10: 上架解析補齊：未知魚種與無單位重量

**What to build:** 對話式上架遇到字典裡沒有的魚種（例如「鮭魚」）時，保留使用者說的名稱、`species_id` 留空，仍可完成上架；沒有單位的重量（例如「石斑 4.5 1 尾」）視為公斤，且不會和價格或尾數混淆。商品上架後，未知魚種沒有料理資料與行情時顯示暫無。（規格：G-1、G-3）

**Blocked by:** 06（魚種單一來源）

**Status:** resolved

- [x] 說「我要賣鮭魚」可走完六個欄位並發布，不再卡在「還缺魚種」。
- [x] 未知魚種商品的 `species_id` 為空，`fish_species` 保留使用者原字串。
- [x] 商品卡與詳情頁對未知魚種顯示「暫無」料理資料／行情，不硬塞成已知魚種。
- [x] 「石斑 4.5 1 尾」可正確解析為 4.5 公斤、1 尾。
- [x] 價格槽位的大數字不會被誤認為重量或尾數。
