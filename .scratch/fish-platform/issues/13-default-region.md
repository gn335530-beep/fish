# 13: 預設地區

**What to build:** 使用者沒有明說地區時，導購一律以個人檔案的縣市為預設，並在回覆中說明「依你的地區」；只有使用者明確指定其他縣市時才改變範圍。（規格：G-5）

**Blocked by:** 無（可立即開始）

**Status:** ready-for-agent

- [ ] 個人檔案有縣市時，說「今天有什麼魚」只回該縣市商品，並在回覆說明地區。
- [ ] 說「新北市有什麼魚」時改用新北市，不套用個人檔案縣市。
- [ ] 個人檔案沒有縣市時，回覆請使用者先補地區，或改為全省查詢並說明目前採用哪一種。
- [ ] 不再只有「附近」「我這邊」才使用個人檔案縣市。
