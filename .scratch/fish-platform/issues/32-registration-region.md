# 32: 註冊填寫縣市

**What to build:** 註冊表單新增縣市（必填）；`POST /api/auth/register` 接受 `city`，驗證縣市清單並把「臺」正規化為「台」。註冊縣市成為商品預設地區；行情查詢由 #25／#29 以同一個 `city` 作預設。既有測試資料沒有縣市時，demo 隨機補一個縣市。只新增縣市欄位；若 #34 已完成，不覆蓋其法規告知與文案。（規格：G-21、AC-15、F1）

**Blocked by:** 無

**Status:** ready-for-agent

- [ ] 註冊表單有縣市欄位，未填不能送出。
- [ ] API 接受 `city`；缺填回 400 `MISSING_REGION`，不在清單回 400 `INVALID_REGION`。
- [ ] 「臺北市」入庫與回應為「台北市」。
- [ ] 註冊縣市成為商品預設 `region`；行情查詢在 #25／#29 以同一個 `city` 作預設，於那兩張驗收。
- [ ] 既有測試資料中沒有 `city` 的使用者，demo 啟動時隨機補一個縣市；已有 `city` 者不覆寫。
- [ ] 個人檔案 `city` 也驗證與正規化。
- [ ] 登入／註冊頁只新增縣市欄位；若 #34 已完成，不覆蓋其法規告知與文案修正。
