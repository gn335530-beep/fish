# 11: 草稿逐欄修改

**What to build:** 草稿卡提供「修改」動作，讓使用者只重問某一個欄位（魚種、總重、尾數、處理方式、照片、售價），其餘已填欄位保留；改完後草稿卡更新，不需整份重填。（規格：G-2）

**Blocked by:** 無（可立即開始）

**Status:** resolved

- [x] 草稿卡有可操作的「修改」入口。
- [x] 選擇單一欄位後，助手只追問該欄位。
- [x] 回答後只更新該欄位，其他欄位與照片保留。
- [x] 修改過程中可取消，取消後草稿維持修改前狀態。
- [x] 六個欄位都能個別修改，包含重新上傳照片。

## Comments

- 2026-10-25：已實作。新增 `demo/ai/editing.js`；草稿卡有魚種／總重／尾數／處理方式／照片／售價六個修改按鈕。`beginEdit` 只追問指定欄位並保存備份，`editText` 只更新該槽位，`editPhoto` 處理照片重傳；輸入「取消」會回到修改前的草稿。面板狀態與草稿卡同步更新。
