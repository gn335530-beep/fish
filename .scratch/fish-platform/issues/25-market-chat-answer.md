# 25: 對話行情問答

**What to build:** 使用者在助手房問「石斑現在多少錢」「今天行情如何」時，助手辨識行情意圖，依魚種與地區查詢行情後回答平均價、縣市或全國平均、交易日期、來源、養殖價格；數字只能來自查詢結果。查無資料時說「目前沒有今天的石斑行情」或「暫時無法取得行情」，不得出現憑空數字或「大約」。（規格：G-6、AC-9、F10）

**Blocked by:** 23

**Status:** ready-for-agent

- [ ] 問「石斑現在多少錢」→ 回平均價、縣市或全國平均、交易日期、來源。
- [ ] 問句有指定縣市時用該縣市；沒指定時用個人檔案縣市，並說明採用的地區。
- [ ] 沒有縣市時用全國平均並說明。
- [ ] `is_aquaculture: true` 時回覆含「養殖價格」。
- [ ] 沒有行情時回「目前沒有今天的石斑行情」或「暫時無法取得行情」，不得出現任何價格數字。
- [ ] 沒有指定魚種時，助手請使用者補充魚種，不猜測。
- [ ] 未知魚種或無官方對照（`NO_MAPPING`）→ 回「目前沒有…行情」，不猜測、不給數字；未知魚種不呼叫行情 API。
- [ ] 助手數字與行情查詢 API 一致。
