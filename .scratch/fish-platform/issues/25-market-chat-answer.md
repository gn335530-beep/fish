# 25: 對話行情問答

**What to build:** 使用者在助手房問「石斑現在多少錢」「今天行情如何」時，助手辨識行情意圖，依魚種與地區查詢行情後回答，數字只能來自查詢結果，並附交易日期與來源。查無資料時說「目前沒有今天的石斑行情」，不得出現憑空數字或「大約」帶過。（規格：G-6、F10）

**Blocked by:** 23（行情查詢 API）

**Status:** ready-for-agent

- [ ] 問「石斑現在多少錢」時，助手回覆均價、縣市或全國平均、交易日期與來源。
- [ ] 問句有指定縣市時用該縣市；沒有指定時用個人檔案縣市，並說明採用的地區。
- [ ] 沒有該魚種行情時回「目前沒有今天的石斑行情」，回覆中不得出現任何價格數字。
- [ ] 沒有指定魚種時，助手請使用者補充魚種，不猜測。
- [ ] 助手回覆的數字與行情查詢 API 的結果一致。
