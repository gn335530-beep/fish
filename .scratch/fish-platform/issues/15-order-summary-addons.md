# 15: 訂單摘要與加購、改量、刪項

**What to build:** 交易房上方顯示可展開的訂單摘要（N 項、M 尾、小計）；買家可加購同一釣客其他可售商品、修改尾數、刪除項目、清空訂單。尾數只能在 1 到可售尾數之間；草稿可以為空，但沒有項目時不能送出協議。（規格：G-10、F6）

**Blocked by:** 14（洽談購買開啟交易房）

**Status:** ready-for-agent

- [ ] 摘要顯示品項數、總尾數與小計，數字與明細一致。
- [ ] 「＋ 加購」只列出同一釣客其他可售商品，選尾數後加入同一訂單。
- [ ] 可把項目尾數改為 1 到可售尾數之間；超出範圍被拒並說明原因。
- [ ] 可刪除單一項目或清空全部；清空後摘要為 0 項。
- [ ] 沒有項目時「協商完畢」不可按。
- [ ] 不同釣客的商品不會出現在同一筆訂單。
