# 03: 漁獲列表改接商品 API

**What to build:** 漁獲列表只使用後端商品 API，不再讀舊格式或靜態示範資料。地區篩選改用縣市（或縣市→大區對照），預設不再把 API 商品全部濾掉；商品卡顯示的釣獲時間是日期，不是 ISO 時間字串。（規格：R-2、B-1、B-2）

**Blocked by:** 無（可立即開始）

**Status:** resolved

- [x] 後端有商品資料時，列表預設就看得到，不需要手動調整篩選。
- [x] 選擇任一縣市能看到該縣市商品；選「全部」能看到所有商品。
- [x] 商品卡的釣獲時間顯示為可讀日期，不出現 ISO 時間字串。
- [x] 後端沒有資料或連線失敗時顯示明確空狀態，不用靜態資料冒充。
- [x] 受影響檔案維持 ≤200 行。
