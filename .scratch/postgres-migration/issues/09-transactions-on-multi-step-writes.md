# 09: 多步驟寫入包交易

**What to build:** 把需要多個資料列一起變更的操作包進資料庫交易，確保要嘛全部成功、要嘛全部回滾；同時讓併發請求不再互相覆寫。

**Blocked by:** 07, 08

**Status:** ready-for-agent

- [ ] 訂單提案、回應、取消與逾時轉換是原子的（訂單狀態＋商品保留／已售＋系統訊息）
- [ ] 評價送出是原子的（評價＋平均星等＋未到次數＋黑名單＋訂單評價狀態與卡片）
- [ ] 交易房刪除是原子的（房間＋訊息＋未成交訂單與項目；已成交訂單與評價保留）
- [ ] 商品建立是原子的（識別碼冪等檢查＋流水號＋寫入）
- [ ] 訊息寫入是原子的（序號＋訊息＋房間最後訊息時間）
- [ ] 每日流水號計數器的讀寫在交易內受保護；併發下不產生重複 ID
- [ ] 以注入失敗的測試證明每個操作要嘛全成功、要嘛全不變
- [ ] API 行為與錯誤碼不變
