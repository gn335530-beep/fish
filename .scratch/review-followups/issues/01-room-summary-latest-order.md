# 01: 收件匣與訂單面板共用「進行中，否則最新」摘要

**What to build:** 交易房完成或取消後，收件匣仍顯示「洽談中」、點進房間時訂單面板退回「尚無訂單」。改為前端只保留一條摘要取值規則：優先使用進行中訂單，沒有才使用最新一筆訂單；收件匣與訂單面板都呼叫同一條規則。助手房仍顯示「AI 對話」；交易房沒有摘要時顯示「洽談中」；訂單面板沒有摘要時顯示「尚無訂單」。已結束訂單只顯示狀態、品項數、尾數與金額，不提供改量、加購、同意或取消操作。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 進行中訂單存在時，收件匣與訂單面板都優先顯示它。
- [x] 只有最新訂單、且已成交或已取消（含逾時）時，兩處都顯示該訂單的狀態與金額。
- [x] 兩者都沒有時，收件匣顯示「洽談中」、訂單面板顯示「尚無訂單」。
- [x] 已結束訂單的面板不出現改量、加購、同意或取消操作。
- [x] 收件匣摘要在 3 秒輪詢內跟上對方的訂單變化。
- [x] 收件匣、訂單面板與交易房測試涵蓋上述優先順序，且全數通過。
