# 06: 商品標題只由後端產生

**What to build:** 商品標題目前前後端各有一套格式，前端在缺少標題時會自行拼出魚種、重量、尾數與處理方式。改為商品標題只由後端產生並隨商品回應回傳；前端商品卡、商品詳情、商品列表與對話中的商品卡都直接使用回應的標題。標題缺漏時顯示通用文案，不拼出可能與後端不同的格式。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 商品卡、商品詳情、商品列表與對話商品卡顯示的標題直接來自商品回應的標題。
- [ ] 缺少標題時顯示通用文案，不以魚種、重量、尾數或處理方式自行拼出格式。
- [ ] API 文件註明商品標題由後端產生並隨商品回應回傳。
- [ ] 前端渲染測試涵蓋缺少標題的情境；既有商品卡與商品詳情測試全綠。

**Source:** `.scratch/review-followups/spec.md` 的「單位、數值與標題」與「文件」。
