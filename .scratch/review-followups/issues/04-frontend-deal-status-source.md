# 04: 前端訂單狀態文案、卡片對應與可操作清單單一來源

**What to build:** 前端目前把訂單狀態文案放在共用模組，卻把訂單狀態到卡片狀態的對應、可操作狀態清單與逾時原因清單留在 demo 層。把這些規則一併收進共用狀態模組：訂單狀態文案、卡片狀態文案、狀態提示、訂單狀態到卡片狀態的對應、可操作狀態清單、逾時原因清單。demo 層只轉出共用模組的函式，不再自行列舉狀態字串。新增一個訂單狀態時只需改共用模組。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 共用狀態模組是唯一列舉訂單狀態文案、卡片文案、狀態提示、訂單狀態到卡片狀態對應、可操作狀態與逾時原因的地方。
- [x] demo 層不再自行列舉狀態字串，只轉出共用模組的函式。
- [x] 每個訂單狀態都有顯示文案；每個可出現的協議卡狀態都有對應的訂單狀態（草稿明確沒有協議卡）。
- [x] 逾時原因仍顯示「已逾時」，不是「已取消」。
- [x] 測試鎖定每個訂單狀態都有文案與卡片對應；交易歷史、協議卡、協議表單、收件匣與訂單面板測試全綠。
