# 04: 聊天面板外殼單一來源

**What to build:** 使用者在首頁、商品列表、登入頁與交易房看到同一個聊天面板外殼。面板、標題列、內文區與頁尾的尺寸、圓角、背景、陰影、grid、overflow 與 transition 只由 chat-frame 負責；deal-bot 只留浮動開啟鈕、badge、bot 容器與手機版定位。載入順序不再決定外觀。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 面板外殼與其標題列、內文區、頁尾的尺寸與 skin 只由一個樣式模組定義。
- [ ] deal-bot 不再重複定義面板、標題列、內文區或頁尾的同一組屬性。
- [ ] 首頁、商品列表、登入頁的面板開啟後尺寸、圓角、背景與關閉狀態一致；交易房面板仍會取代浮動商品條。
- [ ] 桌機與手機的 Playwright 案例通過；沒有水平溢出或面板跳版。
- [ ] 合併後檔案不超過 200 行；過長已依外殼／內容拆檔。
- [ ] `npm test` 與 `npm run test:e2e` 通過。
