# 06: 裸數字依上下文判定重量、尾數或價格

**What to build:** 對話中的裸數字不再一律被當成價格；系統先套用明確單位與標記，再用消去法補重量或尾數，判不出來時只問「重量還是尾數」，不問價格。

**Blocked by:** 04（尾數納入批次追問，後續一次只問一項）

**Status:** ready-for-agent

- [ ] `25 2尾` → 重量 25、尾數 2、價格未填。
- [ ] `3公斤 2` → 重量 3、尾數 2；`250 2尾` → 重量 250、尾數 2。
- [ ] 單獨 `25` → 回問重量或尾數，保留待確認數字，不寫入任何欄位。
- [ ] `2尾 9000` → 9000 不寫入任何欄位；`9000` 在價格步驟或「價格 9000」時才寫入價格。
- [ ] `2台斤` → 1.2 kg；`4.5` → 4.5 kg。
- [ ] 消去法只套用到三位數以內（≤ 999）的裸數字；四位數以上無標記時不自動補欄位。
- [ ] `docs/spec/03-flows.md` 的判定順序改寫；既有「每台斤 200，整批 1000」測試維持通過。
