# 02: 模型自行呼叫在地工具並以設定縣市回答

**What to build:** 口語的天氣／海況問題（例如「今天海上情況」）由模型自行呼叫在地工具 `get_local_conditions`；後端不再因為問題未被認成地區問題就拒絕模型的在地工具呼叫；工具在模型沒帶縣市時改用使用者設定縣市。最終使用者得到與「今天海況如何？」相同的天氣／海況回答。

**Blocked by:** 01.

**Status:** ready-for-agent

- [ ] 「今天海上情況」由模型呼叫 `get_local_conditions(mode=sea)` 並用設定縣市查海況，回覆含浪況／海溫等接地數字。
- [ ] 口語天氣問題由模型呼叫 `get_local_conditions(mode=weather)` 並用設定縣市。
- [ ] 沒設定縣市時，海況回「你想問哪個海域？」，不猜測、不編造。
- [ ] 訊息中明確縣市或海域優先於設定縣市。
- [ ] 回覆的數字、日期與潮汐時間仍來自當輪工具結果；天氣回覆不得混入海況或潮汐。
- [ ] 國外地點天氣仍走網路搜尋，不呼叫在地工具。
- [ ] 平台動作（賣魚／找魚／行情）仍由規則引擎處理，不受影響。
- [ ] 更新原本斷言「非地區問題誤用在地工具會 fallback」的既有測試。
