# 01: 移除時效性強制網路搜尋路由

**What to build:** 第一輪工具路由不再因為「今天／現在／目前」就強制走網路搜尋。口語的地區問題（例如「今天海上情況」）不再被導去網路搜尋，改由模型自行判斷與選擇工具；網路搜尋工具仍保留給模型在真正有時效性時使用。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 「今天海上情況」在開啟網路搜尋時不再被強制導去網路搜尋。
- [ ] 一般新聞（例如「今天有什麼新聞」）仍走網路搜尋，不受影響。
- [ ] 天氣／海況 → 在地工具、商品推薦 → 平台商品、平台意圖不強制等既有路由不受影響。
- [ ] 單元測試涵蓋上述路由行為。
