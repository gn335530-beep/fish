# 02: 自動氣象站目前氣溫

**What to build:** 天氣回答接上中央氣象署 `O-A0001-001` 自動氣象站觀測。後端依縣市在本地過濾測站，選一個有有效溫度、靠近縣市代表點且優先低海拔的測站，回覆目前氣溫與觀測時間。目前天氣現象與風速風向優先使用觀測，觀測缺項時才用 `F-D0047-091`。只有觀測失敗時仍回預報，標示「目前氣溫暫無資料」；不拿預報溫度冒充，也不 fallback 回 Open-Meteo。

**Blocked by:** 01（CWA 官方天氣預報）。

**Status:** resolved

- [x] 使用 `O-A0001-001`；依 `GeoInfo.CountyName` 在後端過濾，不依賴上游 `StationName` 或 `locationName` 篩選。
- [x] 測站選擇：同縣市、`AirTemperature` 不是 `-99`、靠近縣市代表點、優先低海拔；回傳測站名稱、觀測時間與氣溫。
- [x] 回覆包含目前氣溫與觀測時間；目前天氣現象、風速風向與陣風優先使用觀測，缺項才用預報。
- [x] 只有觀測逾時、無測站、溫度缺值或格式錯誤時，仍回 `F-D0047-091` 預報，並標示「目前氣溫暫無資料」。
- [x] 目前氣溫不得使用 `F-D0047-091` 的 12 小時平均溫度；`current_temperature_c` 只放觀測值。
- [x] 要求來源時，天氣來源卡同時列中央氣象署天氣預報與自動氣象站觀測；最多 3 個合法 URL，預設仍不顯示。
- [x] 缺少 `CWA_API_KEY`、預報失敗或觀測失敗時，不呼叫 Open-Meteo 天氣端點。
- [x] 測試以假 CWA（預報＋觀測兩個端點）覆蓋觀測成功、多測站選擇、`-99`、無測站、觀測逾時、只有觀測失敗、來源請求與海況回歸；不呼叫真實網路。
- [x] 相關文件先同步；最終文件一致性由 03 驗收。
- [x] 新增與修改的程式碼檔案不超過 200 行。
