# 03: 基本模式與草稿卡按鈕

**What to build:** 模型正常時，草稿卡只有「確認上架」與「取消上架」；模型逾時、429、無金鑰、上游或格式錯誤時，助手顯示一次「已切換基本模式」、改走規則引擎，草稿卡恢復「修改草稿」，釣客仍能完成上架。基本模式寫進該助手房的 context，重新整理仍維持；`LLM_ENABLED=false` 是正常規則模式，不顯示 AI 故障提示。

**Blocked by:** 02（Walking skeleton：模型驅動的草稿變更與回覆）

**Status:** ready-for-agent

- [ ] 模型正常時，草稿卡沒有「修改草稿」，只有「確認上架」與「取消上架」。
- [ ] 模型逾時、429、無金鑰、上游或格式錯誤時，顯示一次「AI 暫時無法協助，已切換基本模式；你仍可完成上架。」
- [ ] 基本模式改走規則，草稿卡恢復「修改草稿」，釣客可完成上架。
- [ ] 基本模式寫入 conversation context，重新整理仍維持；開新助手房才重新嘗試模型。
- [ ] `LLM_ENABLED=false` 不顯示 AI 故障提示。
- [ ] 模型回覆驗證失敗只丟棄該輪並改用規則，不切換基本模式。
- [ ] 發布中的「上架中…」、停用狀態與防重複行為不變。
- [ ] 後端錯誤碼、前端對話流程與 offline E2E 涵蓋上述行為。
- [ ] `npm test` 與 `npm run test:e2e` 全綠；所有修改與新增的程式檔案低於 200 行。
