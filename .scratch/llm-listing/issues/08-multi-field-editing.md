# 08: 一次修改多個欄位

**What to build:** 釣客在對話中一句話明確提到多個欄位時，助手一次更新所有提到的欄位，不需要按「修改草稿」；模型模式的草稿卡已經沒有該按鈕。模糊數字、聽不出欄位或互相矛盾時回問，不改半套；只改這一則訊息提到的欄位，不對整份草稿做背景重審。

**Blocked by:** 02（Walking skeleton：模型驅動的草稿變更與回覆）、03（基本模式與草稿卡按鈕）、04（魚種解析）、05（魚種錯字修正）、06（處理方式）
