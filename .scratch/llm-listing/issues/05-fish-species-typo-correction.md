# 05: 魚種錯字修正、告知、使用者確認字串與改回

**What to build:** 只原字串查無、修正後剛好對到唯一官方候選時，助手才修正魚種；修正成功時在對話中告知「我把魚種『鬼投刀』修正為『鬼頭刀』」，草稿與官方代碼同步更新。釣客可用文字說「不是，我要保留原字串」把值改回，該字串在同一間助手房不再自動修正；修正歷史要能支撐改回。

**Blocked by:** 04（魚種解析：官方代碼字典、別名、候選與未知魚種）

**Status:** ready-for-agent

- [ ] 只有原字串查無、修正後唯一候選、原值等於草稿、且原字串不在使用者確認字串時，才套用魚種修正。
- [ ] 修正成功時，助手在對話中告知「什麼改成什麼」，草稿與官方代碼同步更新。
- [ ] 合法別名、多候選或原字串已有候選時，即使模型提出修正也被後端拒絕。
- [ ] 釣客說「不是，我要保留原字串」時，助手改回原值、加入使用者確認字串，同一間房不再自動修正。
- [ ] 修正歷史記錄欄位、原值、新值與時間；重新載入助手房仍可改回。
- [ ] 後端驗證失敗時不顯示修正告知，改用安全回覆，避免訊息說改了、草稿沒改。
- [ ] 後端 HTTP 與前端對話流程測試涵蓋上述行為。
- [ ] `npm test` 全綠；所有修改與新增的程式檔案低於 200 行。
