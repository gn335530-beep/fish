# 04: 魚種解析：官方代碼字典、別名、候選與未知魚種

**What to build:** 助手用官方代碼字典解析釣客說的魚種：合法別名保留原文，行情用官方代碼查；多個候選時問「是哪一種？A、B」；完全查無時問一次「仍要上架嗎」；釣客可說「都不是，保留我打的字」。此 ticket 不做錯字修正，只建立解析、候選與未知魚種的完整路徑。

**Blocked by:** 02（Walking skeleton：模型驅動的草稿變更與回覆）

**Status:** ready-for-agent

- [ ] 土魠、土魠魚等合法別名保留釣客原文，不被改成另一個官方名稱；行情用官方代碼查。
- [ ] 商品顯示與發布的魚種仍是釣客原文，官方代碼另存。
- [ ] 多候選時助手問「是哪一種？A、B」，釣客選定後草稿帶入對應官方代碼。
- [ ] 查無魚種時問一次「查不到這個魚種，仍要上架嗎？」；確認後保留原文、代碼留空、行情暫無。
- [ ] 釣客說「都不是，保留我打的字」時，保留原文、代碼留空，同一間助手房不再追問。
- [ ] 釣客改變魚種時，舊代碼與行情失效並重新查詢。
- [ ] 唯讀官方字典查詢工具存在，精確比對，不做模糊搜尋。
- [ ] 後端 HTTP 與前端對話流程測試涵蓋上述行為。
- [ ] `npm test` 全綠；所有修改與新增的程式檔案低於 200 行。
