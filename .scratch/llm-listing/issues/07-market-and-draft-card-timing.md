# 07: 行情卡與草稿卡的時機

**What to build:** 魚種、尾數、處理方式與照片完成前，助手不問售價、不顯示行情卡；所有欄位（含整批售價）完成後才顯示草稿卡。草稿卡出現時，助手在對話中說「想修改直接告訴我」，草稿卡本身不加這行文字。模型要求的卡片動作若時機不對，後端降級成問問題，過早的卡片不會出現。

**Blocked by:** 02（Walking skeleton：模型驅動的草稿變更與回覆）、03（基本模式與草稿卡按鈕）、04（魚種解析）、06（處理方式）

- [ ] 魚種、尾數、處理方式、照片完成前，不顯示行情卡、不問售價。
- [ ] 所有欄位（含整批售價）完成後才顯示草稿卡。
- [ ] 助手在草稿卡出現時說「想修改直接告訴我」，草稿卡本身不加這行。
- [ ] 模型要求的動作時機不對時，後端降級成問問題；過早的卡片不出現。
