# 08: 購物車逐項操作與空車狀態

**What to build:** 把交易房的浮動框補成可用的購物車。文件與程式仍叫「訂單草稿」，UI 可以叫購物車。只有對方有商品時才顯示浮動購物車；對方完全沒有商品時只顯示訊息流與輸入框。草稿為空時顯示「尚未加入商品」、按鈕「選購」與停用的「發送交易」；有商品時每個商品一列，顯示魚種、處理方式（若有）、剩餘尾數與價格，每列有「移除」與數量控制，底部有「加購」與「發送交易」。買家可以逐項移除與改尾數，釣客唯讀。不做「清空全部」；移除與改尾數不留系統訊息，加購（單筆或批次）仍留一則系統訊息。最後一項被移除後回到空草稿狀態；若對方仍有商品，顯示「選購」，不要隱藏浮動框。進行中、已成交、已取消訂單維持現行唯讀規則。草稿為空時「發送交易」停用。
