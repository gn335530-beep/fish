# 07: 評價分布、排序、星等篩選與商品照片

**What to build:** 在角色評價列表上補齊摘要分布、排序、星等篩選與商品照片。每個角色 tab 各自有 5→1 的星等分布、平均分與總數；分布少於 3 則時只顯示摘要與列表，不顯示分布。點分布長條會篩選該星等，列表只顯示該星等，分布本身仍顯示全部。排序提供最新（預設）、最高、最低；星等篩選為 1–5。切換 tab 不影響另一個 tab 的排序與篩選，但重新載入頁面可回到預設。換排序或篩選時 offset 重設。評價卡要從該筆評價的訂單項目快照取得商品照片、魚種與標題，最多 3 張，超過顯示 `+N`；沒有照片顯示 placeholder；照片不連商品頁、不做 lightbox。後端在評價列表加入 `distribution`、`products` 與 `product_count`。
