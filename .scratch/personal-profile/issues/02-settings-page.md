# 02: 設定頁：頭像、暱稱、電話與地址

**What to build:** 新增登入限定的設定頁，讓使用者編輯頭像、暱稱、電話、縣市、區與詳細地址，一次儲存所有變更。頭像沿用既有圖片上傳端點，後端 `avatar_url` 成為唯一真實來源；舊的瀏覽器本機頭像不再使用，也不做自動遷移。電話可修改，格式為 `09` 開頭共 10 碼、全站唯一；修改不要求目前密碼、不重新簽 token，下一次登入使用新電話。儲存成功後更新本機會員資料、導覽列頭像與名字；欄位錯誤顯示在對應欄位，不讓整頁失敗。公開頁不顯示電話與地址。

**Blocked by:** None（可立即開始）

**Status:** resolved

- [x] 未登入開啟設定頁會被導到登入頁
- [x] 頭像可上傳、預覽、移除；沒有頭像時顯示名字首字；儲存後 `avatar_url` 存在後端，重新載入仍可顯示
- [x] 暱稱 2–20 字；電話格式錯誤回 400，重複回 409 `PHONE_TAKEN`；縣市必填並使用既有縣市資料與「台」正規化；區與地址選填且長度沿用現有欄位限制
- [x] 一次送出所有變更；成功後本機會員資料、導覽列頭像與名字同步更新
- [x] 改電話不要求目前密碼、不重新簽 token；修改後 token 仍有效，下一次登入可用新電話
- [x] `avatar_url` 只接受 `/uploads/...` 或空字串；空字串代表移除
- [x] 導覽列與抽屜的頭像以 session 的 `avatar_url` 為來源，不再讀取舊 `localStorage` 頭像
- [x] 公開個人資訊 API 與頁面不回傳或顯示電話、地址與 `username`
- [x] 頁面有 header／footer placeholder、正確載入共用 CSS／JS，且沒有舊 `product-detail` 連結
- [x] 後端測試涵蓋電話格式、重複、token 仍有效與新電話登入；前端測試涵蓋表單驗證、頭像 fallback 與儲存後 nav 更新
