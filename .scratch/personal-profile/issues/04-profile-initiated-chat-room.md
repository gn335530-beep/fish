# 04: 由個人資訊開交易房（含純聊天房）

**What to build:** 讓買家能從別人的個人資訊按「聊聊」開交易房。後端新增由個人資訊開房的端點，請求帶對方的 id；目前使用者是買家、對方是釣客，不能對自己開房。已經有同方向的房間時沿用，不建立第二間；對方有公開商品時找或建立一筆空草稿訂單，對方沒有公開商品時不建立訂單、回傳 `deal: null`，房間只聊天。新房間要有對應的系統訊息；已有進行中訂單時直接回傳該訂單，不建立新草稿。前端在別人的個人資訊顯示「聊聊」，未登入導到登入頁；自己的頁面不顯示。純聊天房不顯示浮動購物車，只顯示訊息流與輸入框，任何時候都可刪除，收件匣不顯示訂單摘要。房間方向固定為「按聊聊的人＝買家、被看的人＝釣客」，反向交易是另一間房。

**Blocked by:** 03

**Status:** resolved

- [x] 開房端點需要登入；`seller_id` 等於自己時回 400 `OWN_PROFILE`
- [x] 同方向房間已存在時沿用；不會產生第二間同方向房間
- [x] 對方有公開商品時建立或沿用空草稿，`has_products: true`，草稿沒有任何項目，系統訊息為「已進入交易洽談。」
- [x] 對方沒有公開商品時不建立任何訂單，回傳 `deal: null`、`has_products: false`，系統訊息為「已開啟對話。」
- [x] 已有進行中訂單時回傳該訂單，不建立新草稿；房間維持現行唯讀規則
- [x] 別人的個人資訊顯示「聊聊」；未登入按聊聊導到登入頁；自己的頁面沒有聊聊
- [x] 按聊聊後開啟面板中的交易房；純聊天房只顯示訊息流與輸入框，不顯示浮動購物車
- [x] 純聊天房隨時可刪除；收件匣不顯示訂單摘要，也不顯示「洽談中」字樣
- [x] 反向交易會建立另一間房，兩間房各自有獨立的訂單與訊息
- [x] 後端測試涵蓋自己開房、有商品、無商品、沿用房間、進行中訂單與純聊天房刪除；前端測試涵蓋聊聊按鈕與購物車隱藏
