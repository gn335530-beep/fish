# 03: 公開個人資訊頁與入口

**What to build:** 新增公開的個人資訊頁，網址帶使用者 id，自己的頁面與別人的頁面共用同一個畫面。標題列顯示頭像（沒有時顯示名字首字）、名字、地區、成交筆數、驗證標章與角色別評分 chips；自己的頁面主要動作是「編輯個人資訊」連到設定頁，別人的頁面暫時不顯示沒有行為的「聊聊」按鈕，等 04 接上。後端新增公開個人資訊端點，只回傳公開欄位白名單，並用評價計算整體、作為釣客、作為買家三種評分。導覽列「我的」改成個人資訊、設定、交易紀錄、上架紀錄、登出；抽屜只保留交易紀錄與上架紀錄，移除舊的個人資訊編輯區。商品卡的「賣家資訊」改成「釣客資訊」並連到個人資訊；推薦小卡維持沒有這個按鈕。

**Blocked by:** 02

**Status:** resolved

- [x] 公開端點不回傳 `username`、密碼、地址、銀行欄位或 `seller_terms_accepted_at`；找不到使用者回 404 `USER_NOT_FOUND`
