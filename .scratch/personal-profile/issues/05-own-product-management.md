# 05: 自己的商品區與管理模式

**What to build:** 在個人資訊頁加入商品區。別人的頁面只顯示可購買商品；自己的頁面顯示全部未刪除商品，包括上架中、洽談中、已售出與已下架。自己的商品區標題列有「管理商品」，按下後變成「完成」，所有卡片進入管理模式；管理模式依商品狀態顯示下架、重新上架或刪除。下架與刪除沿用上架紀錄的確認文案，重新上架不跳確認。操作後卡片留在原位並更新狀態徽章；刪除後卡片移除；下架後別人的頁面立即看不到。個人資訊頁的商品卡隱藏「釣客資訊」；自己的頁面不顯示「洽談購買」，別人的頁面維持可購買與不可購買狀態。商品區不做上架中／已下架／已售出 tabs，也不重複顯示上架紀錄按鈕。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 別人的個人資訊只顯示 `ACTIVE` 與 `PARTIALLY_RESERVED` 商品；自己的頁面顯示全部未刪除商品
- [ ] 商品區顯示商品數量；自己的空狀態為「你還沒有上架商品」，別人的空狀態為「目前沒有上架商品」
- [ ] 自己的商品區有「管理商品」；按下後按鈕變「完成」，卡片進入管理模式；按「完成」離開管理模式
- [ ] 管理模式依狀態顯示動作：上架中／洽談中顯示下架；已下架顯示重新上架與刪除（沒有未售尾數時只有刪除）；已售出顯示刪除
- [ ] 下架與刪除前有確認，文案沿用上架紀錄；重新上架不跳確認
- [ ] 操作後卡片留在原位且狀態徽章更新；刪除後卡片從自己的頁面移除；下架後別人的頁面立即看不到
- [ ] 個人資訊頁的商品卡隱藏「釣客資訊」；自己的頁面不顯示「洽談購買」；別人的頁面顯示「洽談購買」或既有的不可購買文案
- [ ] 商品區不重複顯示「上架紀錄」按鈕；導覽列與抽屜仍保留上架紀錄入口
- [ ] 後端測試涵蓋自己的全部商品與別人的公開商品；前端測試涵蓋管理模式按鈕、完成切換與狀態徽章
