# 09: 交易房角色評價標題列與個人資訊連結

**What to build:** 交易房標題列要顯示對方在目前交易角色下的評價，而不是混合平均。目前使用者是買家時，對方是釣客，使用「買家給的評價」；目前使用者是釣客時，對方是買家，使用「釣客給的評價」。純聊天房沒有訂單，使用對方的整體評價。角色評價數為 0 時顯示「尚無評價」，不要退回整體平均。標題列的對方名字要連到個人資訊；電話仍直接顯示並可撥打，純聊天房也一樣，這是刻意接受的隱私取捨，文件要註明。對話摘要的 peer 可以維持整體評價；交易房開啟後以訂單的 peer 角色評價為準。

**Blocked by:** 04, 06

**Status:** ready-for-agent

- [ ] 交易房的 `GET /api/deals/:id` 依目前使用者的交易角色回傳 peer 角色評價：買家看對方釣客的「買家給的評價」；釣客看對方買家的「釣客給的評價」
- [ ] 標題列使用角色評價的 `rating_score` 與 `review_count`，不混用整體平均
- [ ] 角色評價數為 0 時顯示空心星與「尚無評價」，即使整體平均有數字也不退回
- [ ] 純聊天房沒有訂單時使用對方的整體評價
- [ ] 標題列對方名字連到個人資訊
- [ ] 電話仍顯示並使用 `tel:` 可撥打；純聊天房也顯示
- [ ] 文件註明純聊天房讓第一次聊聊的人能看到電話的隱私取捨
- [ ] 後端測試涵蓋買家視角、釣客視角、角色 0 則與純聊天房；前端測試涵蓋角色評價、尚無評價與名字連結
