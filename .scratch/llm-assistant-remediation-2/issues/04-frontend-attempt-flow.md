# 04: 前端 AI 回覆：首次送出與重試共用流程

**What to build:** 使用者送出訊息與按重試時，走同一個嘗試流程，只有輸入來源與重試狀態的處理不同。重試前置條件與等待中的回覆計數集中在一處，避免兩份實作逐漸分叉。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 首次送出與重試共用同一個嘗試流程；差異只由參數表達。
- [ ] 重試前置條件集中在單一位置：有重試狀態、房間相同、沒有其他等待中的 AI 回覆。
- [ ] 重試成功後清除重試狀態；可重試錯誤更新提示並保留重試按鈕。
- [ ] 重試沿用原本的訊息，不重複寫入使用者訊息。
- [ ] 重試期間送出的新訊息不影響重試結果。
- [ ] 平台意圖不寫入 LLM 文字、商品推薦不被前端關鍵字否決、交易房不呼叫 AI 端點等既有行為不變。
- [ ] 既有前端 AI 測試的斷言不改仍通過。
- [ ] 所有新增或修改的程式碼檔案不超過 200 行。
