# 03: 共用期限工具與全面接上

**What to build:** 所有需要「剩餘毫秒」的地方共用一份期限實作。provider、網路搜尋、行情工具、行情上游與行情快取不再各自建立計時器；行情查詢與上游共用同一個請求期限。使用者看到的逾時行為與錯誤碼不變。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 期限工具提供兩種用法：以剩餘毫秒建立中止訊號（回傳訊號與清理函式），以及以剩餘毫秒與 promise 競速（逾時回傳呼叫端指定結果）。
- [x] 剩餘時間小於或等於零時直接回逾時結果，不呼叫下游。
- [x] provider 與網路搜尋使用中止訊號；行情工具、行情上游與行情快取使用競速結果。
- [x] 行情工具的查詢與上游抓取共用同一個剩餘時間，不得自行建立更長的期限。
- [x] 計時器在成功、失敗與逾時路徑都會清理。
- [x] 行情上游逾時仍映射為 `LLM_TIMEOUT` 並靜默 fallback。
- [x] 一般回覆 8 秒、含網路搜尋的回合 15 秒行為不變；既有逾時測試全部通過。
- [x] 已移除環境變數的回歸測試加上註解，說明「變數已移除、行為固定」的意圖。
- [x] 所有新增或修改的程式碼檔案不超過 200 行。
