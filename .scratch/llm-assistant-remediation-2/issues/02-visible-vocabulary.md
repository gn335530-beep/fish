# 02: 使用者可見用詞與文件一致

**What to build:** 使用者看到的刪除確認與設定說明只用領域詞：交易房、訊息、未成交訂單、已成交訂單、交易紀錄、縣市、區。領域詞彙表只解釋使用者看得見的概念，實作名詞回到技術文件；ADR-0011 回到凍結版本。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 三種交易房刪除確認都不含「聊天室」，並正確區分「未成交訂單」「已成交訂單」與「交易紀錄」。
- [x] 助手房刪除確認維持「確定刪除助手房？」。
- [x] 設定頁說明與表單一致：頭像、暱稱、電話、縣市、區，不再提到地址。
- [x] 領域詞彙表的「資料來源」條目只保留使用者可見描述；意圖升級與工具名稱移到 API 或流程文件。
- [x] ADR-0012 的標題與內文以「對話」表達，決策內容不變。
- [x] 相關規格文件不再以「聊天室」稱呼房間，改用「訊息區」或「對話」。
- [x] ADR-0011 移除工作區新增的段落，維持凍結；強制工具行為記錄在流程或 API 文件。
- [x] 刪除確認相關的前端測試同步更新並通過。
- [x] 歷史文件（trade-room-redesign 與已完成的 review spec）不改。
