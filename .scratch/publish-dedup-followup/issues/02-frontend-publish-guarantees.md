# 02: 前端發布流程鎖定忙碌狀態與識別碼生命週期

**What to build:** 用使用者實際走的發布流程鎖住四個保證：發布進行中草稿卡顯示「上架中…」、三個動作全部停用並帶卡片層級 `aria-busy`；修改草稿後重試仍帶同一個識別碼；成功發布後建立的新草稿會換新識別碼；改版前留下的舊草稿直接發布時不帶識別碼，但第一次以文字修改欄位後會補上，且上架部分失敗後重試沿用同一個。既有切房成功、切房失敗、面板提示與 toast 行為不變。
