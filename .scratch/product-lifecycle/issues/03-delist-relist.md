# 03: 下架與重新上架

**What to build:** 釣客可以在上架中對上架中／洽談中的商品下架；商品從公開列表消失、狀態變已下架、可售尾數視為 0，仍留在上架紀錄。下架時草稿訂單自動移除該商品、洽談中的協議自動取消、等待確認的協議照走；商品已下架時買家退回協議直接取消。已下架且還有未售尾數的商品可以重新上架，最近上架時間更新並回到公開列表最前面。含確認、toast 與 tabs 更新。

**Blocked by:** 02 釣客的上架紀錄抽屜（唯讀）

**Status:** ready-for-agent

- [ ] 上架中／洽談中的商品可下架；下架後公開列表消失、狀態為已下架、可售 0、上架紀錄保留。
- [ ] 下架時草稿訂單移除該商品、洽談中協議取消、等待確認協議照走；交易房有系統訊息。
- [ ] 商品已下架時，買家退回等待確認的協議會直接取消，不進入洽談中。
- [ ] 已下架且還有未售尾數的商品可重新上架；`listed_at` 更新、回到公開列表最前面。
- [ ] 已無未售尾數的已下架商品不顯示重新上架。
- [ ] 下架與重新上架都有確認或明確回饋，列表與 tabs 會更新。
- [ ] 後端與前端測試通過。
