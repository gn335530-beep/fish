# 03: 上架流程移除重量、整批售價必填、新標題格式

**What to build:** 釣客上架時不再需要填重量。對話上架流程移除重量提問與相關槽位，草稿卡也不再顯示總重。建立商品時只要求魚種、尾數、處理方式、照片與整批售價；每台斤售價為選填。若只填每台斤售價，因為沒有重量可換算，回傳「請提供整批售價」。新商品不再產生自動計算的整批售價；舊資料的 weight 與 price_auto 保留但不顯示。商品標題改為「魚種（N尾 / 處理方式）」；商品卡、推薦卡、交易房與協議卡只顯示魚種，長標題只留在系統訊息與訂單摘要。

**Blocked by:** 01（前置重構：拆分面板、交易房與卡片模組）

**Status:** resolved

- [x] 上架對話不再詢問重量，草稿流程不再要求重量槽位。
- [x] 上架草稿卡不再顯示總重。
- [x] 建立商品時整批售價必填、每台斤售價選填；只提供每台斤售價時回傳「請提供整批售價」。
- [x] 新商品不再自動計算整批售價，也不再標記自動計算。
- [x] 新商品標題格式為「魚種（N尾 / 處理方式）」，且使用者可見的商品卡與交易元件只顯示魚種。
- [x] 舊資料的重量與自動計算欄位仍可讀取，但畫面不再依賴或顯示。
- [x] 相關前後端測試已更新，`npm test` 通過，所有程式碼檔案不超過 200 行。
