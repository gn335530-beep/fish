# 06: 聊天室外殼：尺寸、助手標題、白底、語音與圖示送出

**What to build:** 助手房與交易房共用新的面板尺寸：桌機寬度為 `clamp(320px, calc((100vw - 64px) / 3), 400px)`，高度為 `min(520px, calc(100vh - 120px))`；視窗寬度小於等於 760px 時全螢幕。移除寬版交易房。助手房標題列顯示頭像、`AI 聊天小幫手`、`☰`、`─`、`✕`，移除 v7 版本標記與狀態副標；收件匣沿用助手房標題。訊息區改為白底，標題列、頁尾、卡片與按鈕仍可使用品牌色。頁尾由左至右為語音輸入、相機、文字輸入框、送出圖示；送出改為圖示並有 `aria-label="送出"`，移除「送出」文字，輸入上限 500 字。語音使用瀏覽器 Web Speech API，語言 zh-TW、單次辨識，結果附加到輸入框；錄音中顯示 `aria-pressed` 狀態，不支援或權限被拒時顯示明確提示，且不送出空訊息。
