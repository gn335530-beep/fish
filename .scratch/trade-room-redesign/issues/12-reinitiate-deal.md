# 12: 取消後重新發起協議

**What to build:** 協議取消後，畫面留在交易房。商品條顯示最後一筆訂單的商品（魚種、剩餘尾數、每台斤價格）。按下`發送交易`時，若目前沒有進行中的草稿，呼叫重新發起端點，帶上最後一筆已取消訂單的識別碼。後端在同一個交易房建立新的草稿訂單，複製原本項目與數量，每項數量上限為目前可售；可售為 0 的項目略過並提示，只留一則系統訊息。建立成功後展開發送交易面板。若沒有任何項目可重新發起，顯示「目前沒有可重新發起的商品」。重新發起後，商品條與協議流程回到一般狀態。

**Blocked by:** 08（交易房浮動商品條與發送交易面板）、11（協議取消流程與取消訊息卡）

**Status:** ready-for-agent

- [ ] 取消後仍留在交易房，商品條顯示最後一筆訂單的商品、剩餘尾數與每台斤價格。
- [ ] 沒有進行中草稿時按`發送交易`會呼叫重新發起端點，而不是開啟空白面板。
- [ ] 後端在同一交易房建立新草稿，複製原項目與數量，數量以目前可售為上限。
- [ ] 可售為 0 的項目會被略過並提示；重新發起只留一則系統訊息。
- [ ] 重新發起成功後展開發送交易面板，商品條與協議流程回到一般狀態。
- [ ] 沒有任何項目可重新發起時顯示「目前沒有可重新發起的商品」。
