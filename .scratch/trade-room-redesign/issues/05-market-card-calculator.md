# 05: 行情小卡重量試算與單位切換

**What to build:** 行情卡保留魚種、平均價、縣市或全國範圍、7／30 日走勢、最高最低標記、交易日期與來源，並把重量欄位改成即時試算工具。使用者可輸入重量、切換台斤／公斤；參考價格依平均價乘上實際台斤數即時計算，空白或非正數時顯示 `—`。切換單位時換算成同一個實際重量（例如 2 台斤 ↔ 1.2 公斤，小數一位）。每個訊息各自保存重量與單位，切換 7／30 日不重置。底部固定顯示`資料來源：農業部 漁業署`；移除`行情價參考`、`養殖價格`、官方名稱獨立行與`參考整批`。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 卡片標題為`行情卡`，顯示魚種與平均價（元／台斤）、縣市或全國平均、7／30 日切換、走勢圖高低標記、交易日期與`近 N 交易日`。
- [x] 重量輸入可空白；台斤／公斤切換預設台斤，切換時維持同一個實際重量並顯示小數一位。

- [x] 每個訊息分別保存重量與單位，切換 7／30 日不重置。
- [x] 底部顯示`資料來源：農業部 漁業署`，且不再顯示行情價參考、養殖價格、官方名稱獨立行或參考整批。
