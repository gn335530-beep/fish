# 09: 協議卡確認與新內容

**What to build:** 協議卡改成骨架版本：標題為`協議`，狀態徽章為等待確認（coral）、已確認（accent）、已取消（muted）與已逾時（沿用既有狀態）。內容顯示每個項目的魚種（多項逐行）、`販售數量：N 尾`、`最終價格：NT$X`、面交時間與面交地點。等待確認時，收件方（`initiator_id !== user.id`）可看到`確認`；發起人不顯示按鈕；已確認、已取消與已逾時雙方都不顯示按鈕。`確認` 呼叫協議回應 API 的同意動作，雙方輪詢後看到徽章由等待確認變成已確認。

移除`退回`、協商中重新送出流程與行內取消原因下拉。協議卡的`已成交`文案改為`已確認`，但訂單列表仍使用`已成交`；舊資料若已有退回狀態，仍可顯示`已退回`，但新流程不再產生。本票先完成確認路徑；取消按鈕與確認取消卡由 11 接上。

**Blocked by:** 01（前置重構：拆分面板、交易房與卡片模組）、08（交易房浮動商品條與發送交易面板）
