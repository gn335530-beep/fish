# 02: 首頁與今日漁獲的商品卡面；移除商品詳情頁

**What to build:** 首頁與今日漁獲改成骨架的直式商品大卡，買家不必進商品詳情頁就能判斷是否購買。卡片圖片在上（4:5），內容依序為魚種、處理方式徽章、`共 N 尾`、`每台斤售價`（有值才顯示）、`整批售價`、地區與地點，底部並排`賣家資訊`與`洽談購買`。`洽談購買` 以預設數量 1 開啟交易房；`賣家資訊` 目前只保留入口，不開面板、不導頁、不顯示提示。可售量不足時顯示「洽談中，暫無法購買」或「已售出」。同時移除重量、每尾均價、釣獲／上架日期、查看詳情、數量下拉與自動計算標記，並刪除商品詳情頁及所有指向它的連結。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 首頁與今日漁獲使用同一種直式商品卡，資訊順序與規格一致。
- [x] 卡片顯示魚種、處理方式、`共 N 尾`、每台斤售價、整批售價、地區與地點；缺漏地點顯示「地區未提供」。
- [x] `available > 0` 時顯示`賣家資訊`與`洽談購買`；`available <= 0` 且有保留量時，`洽談購買` 換成「洽談中，暫無法購買」；沒有保留量時換成「已售出」。
- [x] `洽談購買` 以預設數量 1 開啟交易房；`賣家資訊` 不執行任何行為，也不註冊動作。
- [x] 商品卡不再顯示重量、每尾均價、釣獲／上架日期、查看詳情、數量下拉或自動計算標記。
- [x] 商品詳情頁與其腳本已刪除，全站不再有指向商品詳情頁的連結；商品查詢 API 保留。
- [x] 相關前端測試已更新，`npm test` 通過，所有程式碼檔案不超過 200 行。
