# 10: 加購面板與批次加購

**What to build:** 商品條加入`加購`入口，點擊後在商品條下方展開面板。面板列出同一位釣客的所有商品（包含已加入訂單的商品），每列顯示魚種、`剩 N 尾`、`N 元/台斤`（沒有時顯示整批價）與加購數量輸入。可再加購尾數為商品目前可售減去該商品已在草稿中的尾數；可再加購為 0 時停用輸入。底部有`取消`與`確認`：`取消`只收起面板，不改訂單；`確認`收集所有大於 0 的列，呼叫批次端點一次加入，只留一則系統訊息，收起面板並重新載入房間。沒有可加購商品時顯示「目前沒有可加購的商品」。

後端新增批次加購端點，驗證同賣家、可售量與草稿狀態，一次加入或累加多個項目，且只留一則系統訊息。

**Blocked by:** 01（前置重構：拆分面板、交易房與卡片模組）、08（交易房浮動商品條與發送交易面板）
