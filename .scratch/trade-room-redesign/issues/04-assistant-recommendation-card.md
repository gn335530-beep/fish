# 04: 助手房橫式詢價推薦小卡

**What to build:** 助手房搜尋結果改用橫式推薦小卡：左側 72px 縮圖，右側顯示魚種＋處理方式、`共 N 尾`、每台斤售價（有值才顯示）、整批售價、地區與`洽談購買`。可售量不足時顯示「洽談中，暫無法購買」或「已售出」，並隱藏購買按鈕。`洽談購買` 以預設數量 1 直接開啟交易房。移除重量、`深入諮詢`、每尾均價、數量下拉與自動計算標記；推薦小卡沒有`賣家資訊`按鈕。

**Blocked by:** 01（前置重構：拆分面板、交易房與卡片模組）

**Status:** ready-for-agent

- [ ] 助手房商品卡為左圖右文橫式配置，縮圖為 72px。
- [ ] 卡片顯示魚種＋處理方式、`共 N 尾`、每台斤售價、整批售價、地區與`洽談購買`。
- [ ] `available > 0` 時顯示`洽談購買`；`available <= 0` 時顯示洽談中或已售出文案，且沒有購買按鈕。
