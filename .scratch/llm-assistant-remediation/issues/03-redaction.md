# 03: 個資遮蔽正確化

**What to build:** 使用者訊息、對話歷史與 context 在送往 Gemini 或 Tavily 前，只遮蔽真正的個資格式；含「路」或「弄」的一般句子不再被誤換成 `[已遮蔽]`，而 `+886` 手機、含括號區碼的市話與含「里／鄰」的地址不再漏遮。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 「網路上的天氣」「我要弄一桌好菜」這類含「路」「弄」的一般文字原樣送給 provider。
- [x] `0912345678`、`+886912345678`、`(02)12345678`、Email、身分證字號與含市／區／路／號及里／鄰的地址都替換成 `[已遮蔽]`。
- [x] 對話歷史、context 中的字串欄位與 Tavily 查詢使用同一套遮蔽規則。
- [x] 端點測試斷言 provider 收到的內容不含上述個資，也不含被錯誤遮蔽的一般文字。
- [x] 遮蔽後的 Tavily 查詢不含原始個資。
- [x] 相關隱私文件若描述遮蔽格式，同步更新。
