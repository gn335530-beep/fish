# 08: 行情工具的模型視圖

**What to build:** 模型只看到回答行情所需的官方平均價、交易日期與必要識別資訊；行情卡仍取得完整歷史，維持既有的 7／30 個交易日走勢。模型不再收到 30 天價格、品質旗標、抓取時間與來源 URL。

**Blocked by:** 01（後端 AI service 拆分與錯誤一致化）

**Status:** resolved

- [x] 模型可見的行情工具結果只含是否查到、官方代碼、官方名稱、地區、交易日期、每公斤與每台斤平均價、養殖標記。
- [x] 模型可見結果不含歷史、品質旗標、抓取時間與來源 URL；這些數字不進入數字防護的證據池。
- [x] API 回給前端的行情資料仍保留卡片所需歷史，行情卡外觀與走勢不變。
- [x] 查無資料時模型只能說「暫無行情」，回覆不得出現數字。
- [x] 端點測試同時斷言 provider 看到的工具結果與回應中給前端的行情資料。
- [x] 文件同步行情工具的模型輸出契約與行情卡的資料來源。
