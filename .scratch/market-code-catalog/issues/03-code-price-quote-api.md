# 03: 代碼查價與整合行情 API

**What to build:** 讓行情可以用官方代碼查詢，並提供一次完成「名稱 → 代碼 → 價格」的整合查詢。回傳代碼、官方名稱、均價、交易日期、縣市或全國平均、來源與養殖旗標。過渡期仍保留舊的 `species_id` 查價，讓既有呼叫端不會中斷。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 用代碼 2141 查價可取得土魠的行情與官方名稱。
- [ ] 用「土魠魚」加縣市查整合行情，可直接取得同一筆結果。
- [ ] 整合查詢遇到多個候選時回傳 `AMBIGUOUS_SPECIES` 與候選清單。
- [ ] 有代碼但當日無交易時回傳 `NO_TRADE_DATA`。
- [ ] 上游失敗但本機有舊行情時，回傳舊行情與實際交易日期。
- [ ] 上游失敗且沒有本機行情時回傳 `UPSTREAM_UNAVAILABLE`。
- [ ] 行情回應包含 `species_code`、`official_name`、平均價、交易日期、來源與養殖旗標。
- [ ] 每次價格查詢仍重抓上游，字典快取不影響價格查詢。
- [ ] 過渡期仍可用舊的 `species_id` 查價。
- [ ] 後端 HTTP 測試涵蓋代碼查價、整合查詢、多候選、查無交易與上游失敗回舊資料。
