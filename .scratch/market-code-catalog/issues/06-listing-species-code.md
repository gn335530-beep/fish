# 06: 上架草稿與行情卡改用 species_code

**What to build:** 上架流程的草稿保存官方魚種代碼，行情卡優先使用代碼查行情。上架「土魠魚」時可看到正確行情卡；魚種對到多個代碼時先請使用者選擇；查無代碼仍可繼續完成上架。

**Blocked by:** 04, 05

**Status:** ready-for-agent

- [ ] 上架「土魠魚」時，草稿同時保存 `fish_species` 與 `species_code`。
- [ ] 上架行情卡使用草稿代碼查詢，顯示代碼、官方名稱、均價、交易日期、來源與參考整批。
- [ ] 魚種對到多個代碼時，先回傳候選讓使用者選擇，不套用錯誤魚種的行情。
- [ ] 修改魚種時同步更新草稿的 `species_code`。
- [ ] 查無代碼時仍可繼續填寫售價並發布商品。
- [ ] 發布商品時會送出 `species_code`。
- [ ] 沒有代碼的商品仍可完成上架。
- [ ] 前端上架流程測試涵蓋有代碼、多候選、查無代碼與修改魚種。
