# 04: 對話問行情改用官方代碼字典

**What to build:** 助手問行情不再只認得舊的 28 種魚。使用者輸入「土魠魚多少錢」時，助手會查官方代碼再查價格；輸入「石斑多少錢」時回傳候選，使用者回覆其中一種後完成查詢；查無魚種代碼時給明確訊息。

**Blocked by:** 01, 03

**Status:** resolved

- [x] 在助手對話輸入「土魠魚多少錢」可取得行情，回覆包含代碼、官方名稱、均價、交易日期與來源。
- [x] 輸入「吳郭魚」「鮭魚」等不在舊 28 種內的魚種也能查詢。
- [x] 輸入「石斑多少錢」時回傳石斑相關候選，不會自動選第一個。
- [x] 使用者回覆候選中的魚種名稱後，可直接完成該魚種的行情查詢。
- [x] 查無魚種代碼時回覆明確的查無訊息，不出現價格數字。
- [x] 有代碼但無交易時回覆「暫無行情」。
- [x] 行情 API 失敗時不出現編造數字；有舊行情時顯示舊行情。
- [x] 對話流程不再依賴舊魚種清單做行情判斷。
- [x] 前端對話測試涵蓋單一候選、多候選追問、查無魚種與無交易。
