# 07: 商品頁與導購移除 species_id／料理資料

**What to build:** 商品卡與商品詳情不再顯示學名、肉質、刺與料理方式，也不再依 `species_id` 判斷未知魚種。商品列表仍可用魚種名稱與地區篩選；導購不再用料理方式與肉質篩選；商品諮詢只回商品資訊。

**Blocked by:** 04, 05

**Status:** resolved

- [x] 商品卡與商品詳情不再顯示學名與料理資料。
- [x] 商品卡不再以 `species_id` 判斷並顯示「未知魚種」。
- [x] 沒有 `species_code` 的商品仍可正常顯示價格、重量、尾數、處理方式與地區。
- [x] 商品列表可用魚種名稱與地區篩選。
- [x] 導購不再使用料理方式或肉質條件篩選商品。
- [x] 商品諮詢回覆只包含商品資訊，不再回覆料理建議。
- [x] 前端商品顯示與導購測試涵蓋無代碼商品、名稱／地區篩選與料理條件移除。

## Comments

2026-10-28 完成。商品卡移除「未知魚種」與「料理資料暫無」，商品詳情移除學名與料理資料列；沒有代碼的商品照常顯示價格、重量、尾數、處理方式與地區。商品列表移除依舊魚種分類的篩選，保留魚種名稱搜尋與縣市篩選。導購改用官方字典比對魚種名稱與 `fish_species`，不再看料理方式、肉質或 `species_id`。商品諮詢只回商品規格。新增 `frontend/test/product-display.test.js` 並改寫導購測試。
