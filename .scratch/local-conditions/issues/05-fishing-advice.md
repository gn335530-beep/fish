# 05: 適合釣魚的一般建議

**What to build:** 使用者問「今天適合釣魚嗎？」時，助手回覆天氣＋海況＋潮汐數據，並依數據給一般建議（偏適合／需注意／偏不適合）。不給絕對保證，也不加固定的「請自行評估」句子；資料不足時不做判斷。

**Blocked by:** 04（潮汐查詢）.

**Status:** ready-for-agent

- [ ] 混合問題使用完整海況包：天氣、海況、潮汐。
- [ ] 建議只依本輪工具取得的資料；可以說「偏適合」「需注意」「偏不適合」。
- [ ] 不使用「保證安全」「一定可以」「絕對沒問題」等絕對說法。
- [ ] 不附加固定的免責句。
- [ ] 資料不足或上游失敗時，只說明缺少什麼，不做適合／不適合的判斷。
- [ ] 單純問天氣或海況時，不自動變成「適合嗎」的建議。
- [ ] 測試涵蓋有建議、資料不足、絕對用語與單純天氣／海況的邊界。
- [ ] 相關文件已同步；新增與修改的程式碼檔案不超過 200 行。
