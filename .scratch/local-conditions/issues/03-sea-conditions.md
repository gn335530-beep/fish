# 03: 海況查詢與海域對照

**What to build:** 使用者問海況時，助手依明確海域或縣市主要海域取得 Open-Meteo Marine 的浪高、浪向、浪週期、海溫，加上該海域的風速陣風與天氣。內陸縣市或海域不明確時反問「你想問哪個海域？」。這一張先不含潮汐。

**Blocked by:** 02（在地天氣查詢）.

**Status:** resolved

- [x] 海況問題使用 Open-Meteo Marine 與海域代表座標的 Open-Meteo Weather。
- [x] 回覆包含浪高、浪向、浪週期、海溫、風速、陣風與天氣，並寫出海域名稱。
- [x] 訊息中明確的海域優先；否則使用縣市主要海域對照。
- [x] 內陸縣市或無法對應海域時，先反問海域，不自行猜測。
- [x] 天氣問題仍然只回天氣，不因海況工具存在而改變。
