# 04: 潮汐查詢

**What to build:** 海況回覆加入中央氣象署潮汐資料的滿潮／乾潮時間。缺少 `CWA_API_KEY` 或查無資料時顯示「潮汐暫無資料」，不編造數字；天氣問題仍然不附潮汐。

**Blocked by:** 03（海況查詢與海域對照）.

**Status:** ready-for-agent

- [ ] 使用中央氣象署潮汐開放資料；`CWA_API_KEY` 由環境變數提供。
- [ ] 海況回覆包含當日滿潮與乾潮時間；必要時可查明天。
- [ ] 每個海域對應一個代表潮位站；對照以中央氣象署正式資料驗證。
- [ ] 缺少金鑰、逾時、無資料或格式錯誤時顯示「潮汐暫無資料」，不產生未經工具支持的數字。
- [ ] 天氣問題不包含潮汐。
- [ ] 測試以假潮汐回應覆蓋成功、缺金鑰、無資料與逾時；不呼叫真實網路。
- [ ] 相關文件已同步；新增與修改的程式碼檔案不超過 200 行。
