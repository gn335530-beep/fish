# 01: 助手地區上下文與暫存縣市

**What to build:** 助手房遇到地區相關問題時，預設使用設定頁縣市；訊息中明確說出的縣市優先。沒有縣市時先反問，使用者回答後只在目前對話暫存，不寫回設定。非地區問題不把縣市送進模型。這一張先以既有網路回答驗證路徑，例如「高雄今天有什麼新聞？」會帶入高雄。

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 地區相關問題（天氣、海況、潮汐、在地新聞、交通、活動、附近、這裡、縣市名稱）使用設定縣市。
- [x] 訊息中明確指定的縣市優先於設定縣市。
- [x] 非地區問題不把縣市放進模型 prompt 或工具查詢。
- [x] 沒有有效縣市時先反問；使用者回答後只在目前對話暫存，不寫回個人設定。
- [x] 暫存縣市按對話隔離、有期限、刪除對話時清除；伺服器重啟後遺失可接受。
- [x] 只使用縣市，不使用區或地址。
- [x] 測試涵蓋 prompt 內容、明確覆寫、缺縣市反問、暫存隔離與過期。
- [x] 相關文件已同步；新增與修改的程式碼檔案不超過 200 行。
