# 07: 明確要求來源時重新查詢並顯示

**What to build:** 使用者明確說「連結、網址、來源、出處、哪裡看、哪個網站、資料哪來、引用、查證」時，重新執行對應的天氣／海況／網路工具，回傳最多 3 個來源並顯示來源卡。同一則訊息要求就同一則給；下一句才問就重新查一次，不做來源暫存。平台意圖不產生網路來源卡。

**Blocked by:** 06（預設不顯示來源與連結）.

**Status:** ready-for-agent

- [ ] 同一則訊息包含來源要求與新問題時，執行新問題對應的工具並附新來源。
- [ ] 下一句只要求來源時，依對話歷史重新執行上一則對應的工具，不重新寫入使用者訊息。
- [ ] 支援天氣、海況、一般網路三種來源；最多 3 個合法 http／https URL。
- [ ] 平台意圖不產生網路來源卡；行情卡維持原本來源標示。
- [ ] 沒有可提供來源時明確說沒有，不編造連結。
- [ ] 不做來源暫存；伺服器重啟後再問會重新查詢。
- [ ] 測試涵蓋同則要求、下一句要求、天氣／海況／網路、平台意圖與無來源。
