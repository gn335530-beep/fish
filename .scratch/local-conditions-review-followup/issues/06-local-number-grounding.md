# 06: 在地氣象數字的嚴格依據

**What to build:** 天氣、海況、潮汐回覆只顯示使用者訊息或當輪工具結果支持的數字。氣溫、海溫、降雨機率、風速、陣風、風級、浪高、浪向、浪週期、潮汐時間與日期都要有依據；不能靠一般單位或小於等於 3 放行。一般知識的數字防護維持不變。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 工具支持 27°C、40%、3 級、1.5 公尺、09:12 時可正常顯示。
- [ ] 模型產生 99 度、90%、8 級、2 公尺或假潮汐時間時被擋下，回覆不顯示這些數字。
- [ ] 潮汐時間與日期不能用「小於等於 3」或一般單位例外放行。
- [ ] 「未來 7 天」有工具依據，不誤擋。
- [ ] 一般知識的「煎 3 分鐘」「長到 1 公斤」等數字不受影響。
- [ ] 未通過時沿用 `LLM_GUARD_REJECTED` 靜默 fallback；不新增錯誤碼。
- [ ] 測試不連網。
