# 01: 地區分類與平台優先

**What to build:** 使用者在助手房問平台問題（行情、賣魚、取消、修改）或一般新聞時，不再被反問「你所在的縣市是哪裡？」。平台意圖永遠優先；一般新聞在沒有縣市時直接走網路搜尋（網路可用時），有設定、暫存或訊息中的縣市時帶入；「在地新聞」「地方新聞」沒有縣市時仍反問；天氣、海況、潮汐、釣魚建議沒有縣市時維持反問。前端平台意圖優先序有回歸測試，即使後端回 `intent:CHAT` 的地區反問也不會蓋掉平台規則。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 「最新行情」在沒有縣市時不回「你所在的縣市是哪裡？」，也不把縣市放進 prompt 或工具查詢。
- [x] 「NBA 新聞」在沒有縣市時不反問；網路搜尋可用時走網路搜尋。
- [x] 「今天有什麼新聞？」有暫存或設定縣市時帶入該縣市；沒有縣市時不反問。
- [x] 「在地新聞」或「地方新聞」沒有縣市時仍反問。
- [x] 天氣、海況、潮汐、釣魚建議沒有縣市時仍反問。
- [x] 平台問題即使同時有「天氣」「新聞」「最新」字樣，也不觸發縣市反問。
- [x] 前端流程測試：後端回 `intent:CHAT` 的地區反問時，行情問題仍由平台規則完成，畫面不出現反問。
- [x] 後端以既有 `POST /api/ai/reply` seam 驗證，前端以既有流程 seam 驗證；測試不連網。
