# 05: 潮汐降級的後端保證

**What to build:** 海況回覆缺少潮汐時，使用者一定看到「潮汐暫無資料」。缺 CWA 金鑰、潮汐逾時、無資料、格式錯誤或沒有代表潮位站都走同一降級；模型漏寫時後端補上，模型已寫時不重複；不產生任何潮汐時間。釣魚建議的既有缺失清單維持。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 缺 CWA 金鑰 → 海況仍回浪況與天氣，回覆含「潮汐暫無資料」，不含潮汐時間。
- [ ] 潮汐逾時、無資料、格式錯誤 → 同上。
- [ ] 模型回覆漏寫「潮汐暫無資料」→ 後端補上。
- [ ] 模型已寫 → 不重複追加。
- [ ] 釣魚建議的缺失清單不出現重複提示。
- [ ] 追加提示後仍遵守回覆長度上限；測試不連網。
