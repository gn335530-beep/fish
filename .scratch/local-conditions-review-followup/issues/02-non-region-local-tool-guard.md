# 02: 非地區問題不反問縣市

**What to build:** 非地區問題（平台、一般知識、一般新聞）即使模型誤呼叫在地工具，也不會反問縣市或顯示模型產生的在地文字；改走 `LLM_GUARD_REJECTED` 或等效安全 fallback。地區問題缺少縣市時仍維持反問。這張完成 01 的後端保證，不讓前端補救成為唯一防線。

**Blocked by:** 01（地區分類與平台優先）

**Status:** resolved

- [x] 非地區問題在沒有縣市時，假模型呼叫在地工具，回覆不出現「你所在的縣市是哪裡？」。
- [x] 上述情況不採用模型產生的在地文字，回 `handled:false` 的 `LLM_GUARD_REJECTED` 或等效安全 fallback。
- [x] 平台問題即使模型呼叫在地工具，平台路由仍優先，不出現地區反問。
