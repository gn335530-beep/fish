# 04: 下一句來源請求的自然說法

**What to build:** 使用者在天氣或網路回答後，用「來源是哪個網站」「這則的來源」「資料哪來」等自然說法要求來源時，後端把它視為純來源請求，依上一則問題重查對應工具並回來源卡，不呼叫模型。平台問題不產生網路來源卡；無法對應或沒有合法來源時回「目前沒有可提供的來源。」。

**Blocked by:** 01（地區分類與平台優先）

**Status:** ready-for-agent

- [ ] 天氣回答後說「來源是哪個網站」→ 不呼叫模型，回上一則天氣來源。
- [ ] 網路／新聞回答後說「資料哪來」→ 重跑網路搜尋，來源最多 3 個合法 URL。
- [ ] 「這則的來源」「引用來源」「查證」等自然說法都算純來源請求。
- [ ] 平台問題的上一則要求來源時，不產生網路來源卡。
- [ ] 無法對應工具或沒有來源時，回「目前沒有可提供的來源。」，不編造連結。
- [ ] 不做來源暫存；測試不連網。
