# 07: 天氣與海況模式的後端強制

**What to build:** 該輪判定為天氣問題時，在地工具只使用天氣模式；模型誤傳海況模式也不會回浪或潮汐。海況、潮汐、釣魚建議使用海況模式，回完整海況包。模式由後端依問題類型決定，不讓模型切換。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 天氣問題的假模型硬傳海況模式 → 工具結果仍是天氣，沒有海況、浪或潮汐。
- [ ] 天氣回覆不出現海況、浪高、浪向、浪週期、海溫或潮汐。
- [ ] 海況、潮汐、釣魚建議 → 完整海況包（浪況、海域天氣、潮汐）。
- [ ] 該輪沒有地區模式時，才允許模型選擇工具模式，不影響既有一般問題。
- [ ] 測試不連網。
