# 行情只引用官方開放資料，查無時說「暫無」

所有對外顯示的行情數字只能來自農業部漁業署的批發交易行情，且必須同時標示來源與交易日期；查無資料時一律顯示「暫無行情」，不得用鄰近魚種、上一次的價格或模型推測補上。助手在對話中同理：沒有工具回傳的數字就不准報價。批發行情只是定價的參考底價，不是售價、也不是保證收購價，因此文案不得寫成「市價」。代價是進口魚種（如鮭魚）與休市日的畫面會是空的，看起來不如「每個魚種都有數字」完整——這是刻意的取捨：一個編造的價格會讓整個行情的可信度歸零，而可信度是這個產品唯一的差異點。
