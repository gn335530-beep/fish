# 商品狀態由數量推導，不落庫

商品的 `ACTIVE` / `PARTIALLY_RESERVED` / `SOLD_OUT` 由「總尾數 − 已售 − 保留」即時算出，不寫進資料。若把狀態存起來，取消訂單、協議逾時釋放、修改尾數、成交這四條路徑都得同步更新它，只要漏掉一處，畫面就會出現「顯示可售但其實賣完」——這種錯誤直接造成重複接單。代價是每次讀取商品都要掃一次進行中訂單，以目前資料量（數十筆）可接受；資料量變大時再加快取，而不是改回落庫。

**Status**: accepted（2026-10-25）

**Considered Options**: 落庫並用排程維護（多一個會過期的真相）；落庫但每次讀取重算覆寫（等於沒落庫，還多寫入成本）。
