# 0014 助手天氣改用中央氣象署預報與自動氣象站

## 背景

助手原先的一般天氣問題走 Open-Meteo，回覆的是模型預報值；「目前氣溫」也是預報溫度，不是實際觀測。使用者希望天氣與中央氣象署官方資訊一致，並看到自動氣象站實測的目前氣溫。海況、浪高、海溫與潮汐已有獨立資料路徑，這次不一起改動。

## 決策

- **一般天氣改用中央氣象署 `F-D0047-091`。** 以縣市名稱查詢 7 日預報，取天氣現象、最高／最低溫、12 小時降雨機率、風向與風速；後端把 12 小時分段整理成每日資料，回覆今天、明天與未來數日。`F-D0047-091` 的 12 小時平均溫度不作為目前氣溫。
- **目前氣溫只來自自動氣象站 `O-A0001-001`。** 後端依 `GeoInfo.CountyName` 在本地過濾，不依賴上游站名篩選；選同縣市、`AirTemperature` 不是 `-99`、靠近縣市代表點且優先低海拔的測站，回傳測站名稱、觀測時間與氣溫。目前天氣現象、風速風向與陣風優先使用觀測，觀測缺項時才用 `F-D0047-091`。
- **失敗不 fallback。** `F-D0047-091` 逾時、5xx、格式錯誤或缺少 `CWA_API_KEY` 時直接回「查不到即時天氣」，不呼叫 Open-Meteo 天氣端點。只有觀測失敗時仍回預報，`current_temperature_c` 為 `null`，回覆標示「目前氣溫暫無資料」。
- **海況維持現狀。** 浪況、海溫與海域天氣仍使用 Open-Meteo Marine／Weather，潮汐仍使用中央氣象署 `F-A0021-001`；天氣切換不改變海況包的欄位或降級行為。
- **來源單一。** 天氣來源卡列中央氣象署天氣預報；有觀測時加上自動氣象站觀測，最多 3 個合法 URL。來源預設隱藏，只有使用者明確要求時才由後端工具結果產生。

## 取捨

- **好處**：天氣與官方預報一致；目前氣溫是實測值並附觀測時間，不再把模型估計當觀測；失敗路徑明確，不會悄悄換來源。
- **代價**：天氣與潮汐都依賴 `CWA_API_KEY`，缺少時兩個功能都降級；自動氣象站是縣市代表站，不是使用者所在港口或釣點；12 小時分段合併成每日資料會失去部分時段細節；沒有快取，每次問題都重新查詢。
- **刻意不做**：海況、海溫或潮汐改用 CWA；天氣快取；區或地址層級天氣；使用者自選氣象 provider；CWA 失敗時 fallback 回 Open-Meteo。

## 替代方案

- **維持 Open-Meteo**：實作最簡單，但天氣不是官方預報，也沒有實測目前氣溫。
- **使用 `F-C0032-001` 今明 36 小時預報**：資料較短，無法回答「這週」；不符合 7 日需求。
- **只依上游站名或縣市參數篩選測站**：上游可能忽略參數或站名不一致；本地以 `GeoInfo.CountyName` 過濾較可預測。
- **CWA 失敗時 fallback 回 Open-Meteo**：使用者會看到來源不一致的天氣，難以判斷是否為官方資料；因此選擇直接回查不到。

## 隱私

- 天氣問題只把縣市名稱送給中央氣象署天氣預報與自動氣象站查詢，不送區、地址、電話或 Email。
- 海況問題仍把海域代表座標送給 Open-Meteo；潮汐只送代表潮位站名稱給中央氣象署。
- `CWA_API_KEY` 只存在後端環境變數；回覆與 log 不包含金鑰。

**Status**: accepted（2026-11-21）

**Considered Options**:

- 維持 Open-Meteo。
- 使用 `F-C0032-001` 今明 36 小時預報。
- 只依上游站名或縣市參數篩選測站。
- CWA 失敗時 fallback 回 Open-Meteo。

**Consequences**:

- `get_local_conditions` 天氣模式改用 `F-D0047-091` 與 `O-A0001-001`；海況模式不變。
- 天氣結果新增 `observation` 與 `observation_error`；`current_temperature_c` 只放觀測值。
- 缺少 `CWA_API_KEY` 時天氣回「查不到即時天氣」、潮汐降級。
- 天氣來源卡可列中央氣象署天氣預報與自動氣象站觀測。
