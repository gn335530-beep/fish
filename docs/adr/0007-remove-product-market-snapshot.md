# 移除商品行情快照，商品卡不顯示行情

商品原本在發布時查一次行情，寫入 `market_snapshot`，商品卡與詳情頁再顯示「新鮮批發參考」。這個設計讓商品資料與行情強耦合：行情快照被刪除或舊商品沒有欄位時，商品卡會出現「暫無行情」；商品改價、行情更新與快照凍結的語意也容易混淆。

改成商品完全不含行情欄位：發布商品不查行情、不寫任何行情資料；商品卡、商品詳情與對話商品卡都不顯示行情。行情只保留在行情 API、AI 問行情回覆與上架行情卡；上架行情卡的文字改為「行情價參考」。

**Status**: accepted（2026-10-28）

**Considered Options**:

- 保留快照並在每次行情查詢時更新：商品卡永遠有最新行情，但快照不再是「發布時凍結」，且查詢會產生商品寫入副作用。
- 保留快照，只回填缺失資料：舊商品可恢復，但新舊商品行為仍依賴快照是否存在。
- 完全移除商品行情欄位（採用）：商品與行情解耦，商品卡不再有「暫無行情」；上架時仍可從行情卡取得定價參考。

**Consequences**:

- `products` 不再有 `market_snapshot`；啟動遷移會移除既有商品上的欄位。
- `POST /api/products/create` 不再呼叫行情上游，發布速度不受行情影響。
- 商品卡、商品詳情、聊天商品卡移除行情區塊與相關 CSS。
- 上架行情卡保留，文字由「新鮮批發參考」改為「行情價參考」。
- 訂單項目的商品快照是另一份資料，不受本決策影響。
