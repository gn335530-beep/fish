# 交易房以一組釣客與買家為單位

同一位釣客與同一位買家之間的所有交易都放在同一個交易房，而不是每個商品一間房。買家同時買石斑與嘉鱲時，會在同一間房、同一筆訂單完成，只出現一次協議、一次面交；若以商品為單位，同一組人會產生多間房、多份協議、兩次面交，而雙方其實只見過一次面。代價是交易房不再對應單一商品，訂單必須自己攜帶商品快照，且同一房內會出現「一筆草稿＋一筆進行中訂單」的並存規則。

**Status**: accepted（2026-10-25）

**Considered Options**: 每個商品一間房（介面直覺，但同一組人會分裂成多間）；每筆訂單一間房（乾淨，但重複購買時要一直開新房，對話歷史斷裂）。
