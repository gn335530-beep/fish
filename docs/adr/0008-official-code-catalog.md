# 0008 以官方代碼字典取代固定魚種清單

## 背景

原本系統在前端與後端各維護一份 28 種魚的清單，並用 `species_id` 串接商品、學名、料理資料與行情代碼。官方行情每天出現 200 多個新鮮代碼，固定清單無法涵蓋；使用者輸入「土魠魚」「吳郭魚」時，系統會在第一步就被白名單擋掉。

## 決策

- 魚種來源改為執行時同步的「官方新鮮代碼字典」。
- 查詢以官方代碼為唯一鍵；同一代碼跨日期的多個官方名稱全部保留為別名。
- 名稱解析只做精確官方名稱、精確別名與純數字代碼，不做模糊搜尋。
- 同名對到多個代碼時一律回傳候選，不自動選擇。
- 前端移除固定魚種清單、`species_id`、學名與料理資料；商品只保留 `fish_species` 與可選 `species_code`。
- 舊商品在啟動時清除 `species_id`、`species_latin`，保留 `fish_species`，`species_code` 設為 `null`。
- 字典同步最近 30 天官方資料，排除 3xxx 凍結與 6xxx 加工代碼；成功後快取 24 小時，失敗時沿用舊字典。

## 取捨

- **好處**：涵蓋官方每天出現的新代碼；不再需要人工維護對照表；未知魚種仍可上架。
- **代價**：第一次查詢可能需要同步字典，多 1–3 秒；官方名稱會隨日期與市場變動，因此查詢以代碼為準。
- **刻意不做**：模糊搜尋、注音搜尋、錯字修正、自動選第一個候選。寧可多問一次，也不要查錯魚種。
- 與 ADR 0003（行情只引用官方資料）、0006（每次價格查詢重抓）相容；不恢復商品行情快照（ADR 0007）。
