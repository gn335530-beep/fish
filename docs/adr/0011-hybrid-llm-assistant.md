# 0011 混合式 LLM 助手：規則引擎負責平台動作，模型只負責理解與文字

## 背景

助手房原本只有規則引擎：固定的賣魚、找魚、行情與取消指令可以運作，但換一種說法就只剩「你是想賣魚，還是想找魚？」。使用者需要自然語言理解、一般知識、即時網路問答與平台商品推薦，同時不能讓模型編造價格、庫存或行情，也不能把交易房的私人對話送給外部服務。

平台目前是本機開發用的 JSON 後端，沒有付費雲端預算，也沒有正式上線的 SLA、稽核或資料落地承諾。因此第一版必須能在免費層額度內運作，且外部服務失效時不能拖垮買魚、賣魚與查行情。

## 決策

- **混合式架構，不把平台動作交給模型。** 模型只回傳 `intent`、`slots`、`reply_text` 與唯讀工具結果；上架草稿、行情卡、商品卡、訂單、協議與取消流程仍由既有規則引擎驗證與執行。
- **模型只負責三類文字：** 一般知識（`CHAT`）、有時效性的網路回答（`WEB`）與平台商品推薦（`PRODUCT_RECOMMEND`）。平台意圖（`SELL`、`BUY`、`MARKET`、`CANCEL`、`EDIT`）不產生模型文字，避免同一輪出現兩套答案。
- **只有唯讀工具。** `get_market_price`、`search_products`、`web_search`、`get_local_conditions`（中央氣象署天氣預報、Open-Meteo 海況、中央氣象署潮汐）由後端執行；模型不能建立、修改、發布、下架或刪除商品，也不能建立訂單、送出協議或寫評價。每輪最多 2 次工具呼叫。
- **平台數字嚴格防護。** 價格、尾數、行情、庫存與日期只能來自使用者訊息或工具結果；模型自行產生的數字與商品卡一律丟棄並 fallback。模型自行提供的來源丟棄，回覆文字中的 URL 移除；`sources` 預設為空，只有明確要求來源時才回傳後端工具結果。
- **外部內容視為不可信資料。** 網頁結果中的指令不得改變平台規則、揭露 system prompt 或觸發寫入；平台資料與網路資料在 UI 上清楚分開。
- **助手房才能使用模型。** 交易房完全不呼叫 LLM；歷史只取助手房最近 10 則使用者／助手訊息，卡片以一行摘要取代，電話、Email、身分證字號與地址先遮蔽。
- **免費層 beta。** 使用 Google AI Studio（Gemini Developer API）免費層與 Tavily 免費層；`LLM_ENABLED` 預設關閉，`LLM_WEB_SEARCH` 預設關閉，缺少金鑰時不呼叫外部服務。模型與逾時可用環境變數更換。
- **錯誤分流。** 逾時、5xx、格式錯誤、數字防護失敗與未設定時靜默回到規則；Gemini 429、Tavily 429 與 Tavily 額度用完時，先跑規則，規則無法處理才顯示提示與重試按鈕。重試沿用同一個 `message_id`，不重寫使用者訊息；不自動排隊、不自動重試、不快取搜尋結果。
- **soft launch，不是正式上線。** 不強制邀請名單、不設 app 層使用額度、不承諾 SLA。免費層內容可能被 Google 用於改善產品，Tavily 也會收到該次搜尋查詢，天氣會把縣市送給中央氣象署，海況會把海域座標送給 Open-Meteo，潮汐會把代表潮位站名稱送給中央氣象署；這些限制寫在 README 與 beta 說明，不在 UI 顯示。

## 取捨

- **好處**：平台流程維持可預測、可測試，模型故障或額度用完時仍能完成交易；模型只接觸白名單歷史與唯讀工具，隱私與資料寫入風險較低；provider 與搜尋 adapter 可替換，未來升級不必重寫前端流程。
- **代價**：自然語言能力受 intent／slots schema 限制；平台意圖不能同時側聊；免費層有 RPM／RPD／TPM 與每月 1,000 Tavily credits 的硬限制；網路回答可能因額度用完而暫停；沒有串流，使用者需等待完整回覆。
- **刻意不做**：交易房 AI、模型寫入工具、邀請制名單、app 使用額度、UI 免費層隱私提示、串流、多模態、圖片／語音理解、模型選擇器、自動重試與搜尋快取。

## 替代方案

- **全 LLM＋寫入工具**：模型直接建立或修改商品、訂單與協議。自然語言最自由，但需要完整的權限、確認與稽核設計，任何 prompt injection 或數字幻覺都可能造成實際交易錯誤。
- **維持純規則引擎**：最穩定、零外部依賴，但無法回答一般知識、即時網路問題或跨魚種比較，也無法推薦平台商品。
- **Vertex AI＋Google Search grounding**：搜尋品質與資料來源較完整，但需要 Google Cloud 專案、ADC／服務帳戶與付費層，超出目前 beta 的維運範圍。
- **自架或本地模型**：可避免資料外送，但本機後端沒有推論資源，維運與品質成本更高。

## 遷移路徑

- provider 與 web search adapter 保持可替換：升級時只改設定與認證，不動 intent／slots、防護、工具 schema 或前端流程。
- 若 beta 驗證成功，優先升級到 AI Studio 付費層＋Google Search grounding，或 Vertex AI＋Google Search grounding；以 grounding 取代 Tavily，`sources` 仍由後端工具結果產生。
- 公開放大前再補 allowlist、app 層使用額度、UI 隱私提示、正式稽核與資料落地政策；這些不在目前 beta 承諾內。

**Status**: accepted（2026-11-14）

**Considered Options**:

- 全 LLM＋寫入工具。
- 維持純規則引擎。
- Vertex AI＋Google Search grounding。
- 自架或本地模型。

**Consequences**:

- 平台動作仍由規則引擎驗證；模型只能提供 intent、slots 與文字。
- 後端端點 `POST /api/ai/reply` 不寫訊息、不改 context；AI 訊息仍由前端用既有訊息端點寫入。
- 新增 `sources` 卡片型別；預設為空，只有明確要求來源時才回傳並顯示，回覆文字中的 URL 會移除。配額提示是 transient UI 狀態，不寫入訊息。
- `LLM_ENABLED=false`、缺少金鑰或外部服務失敗時，助手房仍可用規則完成上架、找魚與行情。
- 免費層限制與資料使用方式只寫在 README／beta 說明，不在 UI 顯示。
- 在地天氣／海況／潮汐、來源預設隱藏與國外地點路由見 [ADR-0013](./0013-local-conditions-and-hidden-sources.md)。
