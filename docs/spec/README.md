## 這份文件是什麼

把你現在有的東西寫成唯一可引用的規格：**已經做到的、做得不完整的、還沒開始的**，全部放在同一組文件裡，並誠實標記狀態。

它同時回答三個問題：

1. 這個系統現在實際會做什麼（不是計畫書說它會做什麼）。
2. 哪些行為是刻意的、不能「順手改掉」的。
3. 接下來要補什麼，補完的驗收條件是什麼。

## 狀態標記

每個功能都用這四種標記之一，**不寫完成度百分比**（百分比兩週後就是錯的資訊）。

| 標記 | 意思 |
| --- | --- |
| ✅ 已實作 | 程式現在就會這樣做，且有檔案依據 |
| 🟡 部分實作 | 主路徑可用，但明確列出缺口 |
| ⬜ 未實作 | 只有規格，沒有程式 |
| 🗑 待移除 | 還在程式裡，但已決定不要了 |

## 文件優先序

出現衝突時，依序以下列來源為準：

1. `docs/spec/`（本組文件）
2. `docs/adr/`
3. `GLOSSARY.md`（用語）
4. 程式碼註解

舊的 `docs/fishmatch-dealing-engine-plan.md` 與 `docs/fishmatch-market-price-spec.md` 已移除，不再列入優先序。

## 維護規則

- 改行為之前先改這組文件；文件與程式不一致時，視為缺陷。
- 實作完成時把標記從 ⬜ 改成 ✅，並在 `07-roadmap.md` 勾掉對應項目。
- 任何「為什麼不這樣做」的答案，寫進對應章節的小註解或 ADR，不要只留在對話紀錄裡。
- 不把實作細節寫進 `GLOSSARY.md`；它是詞典，不是規格。

## 一句話現況

使用者可以登入、在對話裡上架漁獲、用對話找魚、收發訊息；交易房、訂單、協議與評價已實作。舊購物車與手動上架表單已移除；行情已接官方資料，按需抓取與查詢 API 可用，行情卡、商品快照與助手行情問答仍待實作。
