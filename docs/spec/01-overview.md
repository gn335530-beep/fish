# 01 總覽

## 一句話

休閒釣客把當日親手釣到的漁獲，用一個聊天視窗直接賣給附近的人；批發行情只當定價的參考底價。

## 產品定位

| 項目 | 內容 |
| --- | --- |
| 賣什麼 | 休閒一支釣的當日漁獲，整批或拆尾販售 |
| 賣給誰 | 想吃當日現釣、願意面交的消費者 |
| 差異點 | 來源可追溯（誰釣的、何時釣的、怎麼處理的）、價格有官方行情可對照 |
| 不做的 | 金流、運費、訂金、發票、冷凍物流、批發競價、行情預測 |

## 三個角色

| 角色 | 說明 |
| --- | --- |
| 使用者 | 單一帳號型態，**同一個帳號可以買也可以賣**。`role` 欄位只是顯示標籤，不影響任何權限 |
| 助手 | 平台端的規則式對話代理，負責上架追問、導購、商品諮詢。掛在助手房裡，不是真人 |
| 對方 | 交易房中的另一位使用者（釣客或買家） |

## 五個設計原則

1. **對話就是介面。** 上架、找魚、洽談、協議都在同一個面板完成；網頁只負責瀏覽與登入。沒有第二套上架表單。
2. **商品只有一個模型。** 後端 `products` 是唯一真實來源；不容許「舊格式 `/api/fish/data`」與「新格式 `/api/products`」並存於畫面。
3. **狀態由數量推導。** 可售尾數、保留尾數、商品狀態都是算出來的，不落庫（見 ADR 0002）。
4. **行情只讀官方資料。** 查詢時按需抓取單一魚種並快取，查無資料就說暫無，不用示意值填空（見 ADR 0003、0004）。
5. **交易在房間裡完成。** 一組釣客與買家一間交易房，一筆訂單可以有多個商品（見 ADR 0001）。

## 範圍

### 本版包含

- 註冊、登入、個人檔案與地址
- 對話式上架（魚種、重量、尾數、處理方式、照片、售價；售價可填每台斤或整批）
- 對話式導購、商品卡、料理諮詢
- 助手房（可多間）、收件匣新增／刪除、未讀、3 秒輪詢
- 交易房、訂單草稿、加購、協議簽核、逾時釋放
- 雙向評價與交易紀錄
- 註冊填寫縣市
- 販賣法規告知與第一次販賣確認
- 批發行情按需抓取、查詢、上架行情卡、商品快照、前端顯示

### 本版明確不做

| 項目 | 理由 |
| --- | --- |
| 金流與退款 | 面交現金，平台不碰錢 |
| 運費與物流 | 只支援面交 |
| 訂金 | 同上 |
| 購物車 | 已被交易房取代，**本版移除** |
| 手動多步驟上架表單 | 與對話上架重複，**本版廢止** |
| 真實 LLM | 先預留介面；行情工具等接 LLM 時一併做 |
| 推播 | 只有站內紅點 |
| 多語系 | 繁體中文 |
| 行情預測 | 只呈現歷史與當日 |

## 系統組成

```
frontend/            靜態網站（HTML + 原生 JS 模組）
  pages/             index / products / product-detail / login
  assets/js/api/     API 用戶端、商品、魚種與會員狀態
  assets/js/app/     共用 UI、抽屜、導覽
  assets/js/demo/    對話式交易引擎（助手面板）
backend/             本機開發用 API（json-server + 自訂路由）
  routes/            auth / products / chat / chat-messages / uploads
  lib/               權限、訂單計算、對話摘要、魚種
  db.json            單一 JSON 資料庫
docs/                規格、ADR、歷史計畫
```

- 前端是純靜態檔案，沒有建置流程；以 `frontend/` 為網站根目錄。
- 後端不是正式後端：資料存在 `db.json`、Token 存在記憶體、密碼明文。**不可用於正式環境**。
- 行情沒有每日全量 job；查詢時按需抓取單一魚種並快取，另有一支手動 CLI。

## 命名沿革

| 名稱 | 出現位置 | 狀態 |
| --- | --- | --- |
| 一支釣 | 本規格、頁面標題、助手面板標題 | **正式名稱** |
| 海人直送 | 舊文件與 `haisen_*` 儲存鍵 | 歷史名稱；UI 已全面改為一支釣 |
| FishMatch | `FishMatchBot`、`FISHMATCH_BUILD`、console 訊息、後端啟動訊息 | 歷史名稱，程式識別字暫不動 |
| 澎湖一支釣漁獲交易平台 | 已移除的 `report.html` | 歷史名稱，且範圍錯誤（全台） |

程式內的 `haisen_*`（localStorage 六個鍵）、`HaisenAPI`、`window.FishMatchBot`、`package.json` 的 `haisen-fish-market` **本版不改**：改 key 需要寫遷移邏輯，與規格無關。UI 可見文字已改為「一支釣」。
