## 5. 里程碑

### M1 收斂（不新增功能）

**做**：R-1～R-12、B-1～B-7。
**產出**：只有一套商品模型、沒有購物車與手動上架表單、文件與程式一致、UI 叫「一支釣」。
**驗收**：全站沒有 404 的 API 呼叫；商品列表預設能看到 API 商品；檔案 ≤ 200 行；`docs/spec` 的 ✅ 與程式一致。

### M2 交易房與訂單（G-7～G-10）

**做**：`deals` 路由（initiate-channel、items 批次加購）、交易房視圖、浮動商品條、批次加購、輪詢接上交易房。
**驗收**：買家對同一釣客的兩個商品加購 → 同一房、同一訂單、小計正確；另一瀏覽器 3 秒內看到訊息；`deals` 有一筆 `DRAFT`。

### M3 協議（G-11、R-11）

**做**：propose／respond／cancel、協議卡、30 分鎖定、15 分保留、逾時掃描補齊。
**驗收**：提案 → 對方確認；`sold_quantity` 與商品狀態正確；取消後尾數立即釋放並留下取消卡；逾時自動取消並留系統訊息。

### M4 評價與交易紀錄（G-12）

**做**：`/api/reviews/submit`、評價卡、平均星等重算、黑名單、抽屜「交易紀錄」。
**驗收**：雙方各評一次，對方 `rating_score` 更新；重複評價回 409；交易紀錄看得到多品項快照。

### M5 行情（G-13～G-16、B-8）

**做**：兩份對照表（#21）→ 按需抓取與快取（#22）→ 查詢 API 與 history（#23）→ 對話問答（#25）。沒有每日全量 job。
**現況**：2026-10-27 已完成 #21～#25（行情問答）；2026-10-28 起查詢 API 每次重抓，商品不再保存行情快照。
**驗收**：見下方 AC-1～AC-9。

### M5.1 上架售價與行情卡（G-17～G-19）

**做**：處理方式自由文字（#26）→ 每台斤／整批售價（#27）→ 批次追問（#28）→ 行情卡與售價引導（#29）。
**現況**：2026-10-27 已完成 #26～#29，含 7／30 交易日行情卡與售價引導；交易房改版後改為整批售價必填、不再自動計算。
**驗收**：AC-10～AC-11。

### M5.2 對話、收件匣與註冊（G-20～G-22）

**做**：多間 AI 對話（#30）與對話刪除（#31）→ 註冊縣市（#32）→ 草稿修改與取消上架（#33）。
**現況**：2026-10-27 已完成 #30～#33，含多間助手房、刪除規則、註冊縣市、草稿修改與取消上架。
**驗收**：AC-12～AC-15。

### M5.3 販賣法規告知與確認（G-23）

**做**：登入／註冊左側法規告知與文案修正 → 第一次販賣法規告知卡 → `seller-consent` 記錄 → 永久跳過（#34）。
**現況**：2026-10-27 已完成 #34。
**驗收**：AC-16～AC-19。

### M5.4 交易房聊天室畫面重製（G-24）

**做**：商品卡面與商品詳情頁移除 → 詢價推薦小卡 → 行情小卡與重量試算 → 聊天室外殼（`paper-2` 訊息區、語音、送出圖示）→ 交易房標題列星星與電話 → 浮動商品條與發送交易 → 協議卡與取消流程 → 批次加購與重新發起 → 評價小卡 → 文件同步與舊文案清除。

**驗收**：AC-20～AC-39。

| AC-15 | 註冊 | 未填縣市回 400；填「臺北市」入庫為「台北市」；demo 種子資料皆已含合法縣市，啟動不補值 |

## 7. 端到端驗收腳本（兩個瀏覽器）

準備：Chrome 登入 `0912345678 / seller123`（釣客）；Edge 無痕登入 `0987654321 / buyer123`（買家）。註冊時填新北市。

1. 釣客說「我要賣花枝」→ 助手先顯示法規告知卡 → 按「我已了解並確認」→ 先前對話清除，只問「請問想要販售什麼魚類？」→ 回「花枝」→ 助手問尾數、處理方式與商品照片 → 一次輸入「2 尾 放血冰鎮」＋上傳照片 → 行情卡顯示平均價、7 日走勢與重量試算 → 回「每台斤 200，整批 1000」→ 確認上架。
2. 再上架「石斑 1 尾 放血冰鎮 2800」；行情卡顯示石斑行情；已帶售價，不再問價格，直接確認上架。
3. 再上架「嘉鱲 2 尾 放血冰鎮 2200」；商品列表出現三筆直式商品卡，顯示魚種、處理方式、尾數、價格與地區，沒有重量。
4. 買家在個人檔案填「新北市 / 瑞芳區 / 鼻頭路 1 號」。
5. 買家說「附近有什麼魚」→ 依新北市推薦，助手房顯示橫式推薦小卡。
6. 點石斑「洽談購買」→ 以數量 1 進入交易房，看到對方名稱、星星、電話與浮動商品條。
7. 按「加購」→ 勾選嘉鱲 2 尾 → 批次確認 → 商品條 2 項、小計 5000。
8. 按「發送交易」→ 整單 4800、基隆火車站南站、17:30。
9. 釣客 3 秒內看到紅點 → 協議卡顯示 2 個魚種；發起人沒有按鈕。
10. 釣客按「確認」→ 徽章變「已確認」；雙方看到評價卡。
11. 兩項商品 `sold_quantity` 正確，狀態更新。
12. 雙方各評 5 星、選標籤 → 對方平均星等更新。
13. 買家抽屜「交易紀錄」→ 看到 2 個品項的快照與成交金額。
14. 兩邊重新整理 → 訊息、訂單、評價都還在。
15. 買家問「石斑現在多少錢」→ 有行情就回行情卡（平均價、日期、來源、走勢）；沒有就說「暫無行情」，**不得出現憑空的數字**。
16. 另一筆交易取消：買家按協議卡「取消」→ 填自由文字原因 → 送出 → 雙方看到「協議已被取消」卡；買家再按「發送交易」→ 重新發起成功。
17. 釣客說「取消上架」→ 助手問確認 → 確認後目前 AI 對話刪除，直接開啟一間新的 AI 對話，不跳回收件匣。
18. 收件匣「新增 AI 對話」→ 新對話有自己的草稿；刪除一間已取消交易房 → 對話、訂單與項目消失，交易紀錄不再顯示。
19. 上架海鱸 → 行情卡不顯示「養殖價格」標記。
