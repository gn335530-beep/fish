## 2. 助手面板

### 2.1 外殼

```
┌──────────────────────────────────────────┐
│ 魚  一支釣小幫手 v3                  ☰ ─ ✕ │
│     找魚・上架・交易                       │
├──────────────────────────────────────────┤
│ 訊息流                                    │
├──────────────────────────────────────────┤
│ 📷  輸入訊息…                      送出    │
└──────────────────────────────────────────┘
                              ✦ ⑤  ← 浮動按鈕＋未讀
```

| 元素 | 行為 |
| --- | --- |
| 浮動按鈕 | 開啟／關閉面板；未讀數 > 0 顯示紅點，超過 99 顯示 `99+` |
| 標題列 | 助手名稱＋狀態列；`☰` 開收件匣、`─` 縮小、`✕` 關閉 |
| 狀態列 | 未登入 / 收件匣 / 上架中 / 找魚中 / 找魚・上架・交易 / 與 {對方} 洽談中 |
| 輸入框 | 上限 500 字；`Esc` 關閉面板；送出後清空 |
| 相機按鈕 | 選一張圖 → 壓縮 → 上傳 → 送出圖片訊息 |
| 尺寸 | 桌機寬度 `clamp(320px, (100vw−64px)/3, 400px)`、高 `min(520px, 100vh−120px)`；交易房 `440 × min(760px, 100vh−100px)`；視窗 ≤ 760px 時全螢幕 |

### 2.2 三種視圖

| 視圖 | 內容 | 狀態 |
| --- | --- | --- |
| 對話 | 訊息流＋輸入框 | ✅ |
| 收件匣 | 房間清單（對方、最後訊息、未讀、訂單摘要）＋新增 AI 對話＋刪除 | 🟡 |
| 交易房 | 電話橫幅、可展開的訂單摘要、訊息流、輸入框 | ✅ |

**收件匣（目標）**：頂部有「新增 AI 對話」；每張 AI 對話卡片右上角有 X，點擊先問「確定刪除聊天室？」。交易房只有在沒有 `CONFIRMED` 歷史、且目前訂單 `CANCELLED` 時顯示 X；刪除交易房會一併移除訂單與項目，交易紀錄不再顯示。

**訂單摘要**：標題列顯示狀態、`N 項 · M 尾 · NT$小計`；展開後列出每個商品與小計。買家可加購、改尾數、刪除、清空；草稿沒有項目時「協商完畢」停用。送出協議後顯示整單金額、面交地點與時間。

### 2.3 未登入

- 面板可以開，但只顯示登入引導，不能送出訊息。
- 與舊計畫書不同：**未登入不能導購**，因為助手房需要登入才能建立。
- 個人抽屜未登入時顯示「請先登入」與登入連結。

### 2.4 個人抽屜

| 視圖 | 內容 | 狀態 |
| --- | --- | --- |
| 個人資訊 | 頭像、暱稱、電話 | ✅ |
| 交易紀錄 | 所有訂單的狀態、時間、對方、品項數、金額與評價狀態 | ✅ |
| 訂單詳情 | 多品項快照（照片、品名、尾數、單價）、面交資訊、評價狀態 | ✅ |

- 抽屜上方有「交易紀錄」入口；導覽列的「我的」也有直接入口。
- 列表依建立時間由新到舊；沒有訂單時顯示「目前沒有交易紀錄。」
- 已取消交易房若被刪除，交易紀錄不再顯示該筆。
- 未登入時顯示登入引導。

### 2.5 錯誤處理

- 操作失敗在訊息流頂端顯示一則提示，4 秒後消失。
- 401／403 時自動登出並回到未登入畫面。
- 載入失敗不得顯示示意資料冒充真實資料。

## 3. 訊息與卡片

### 3.1 訊息氣泡

| 型別 | 呈現 |
| --- | --- |
| 文字 | 左右分邊（自己／對方），助手訊息靠左 |
| 圖片 | 縮圖，點擊另開 |
| 系統 | 置中灰字，不計入未讀 |
| 卡片 | 見下 |

### 3.2 卡片

| 卡片 | 內容 | 動作 | 狀態 |
| --- | --- | --- | --- |
| 商品卡 | 照片、標題、整批價、每台斤售價（可選）、每尾均價、行情快照、重量／尾數／處理、地區與可售尾數 | 深入諮詢、洽談購買（選尾數） | 🟡 行情快照與養殖標記未實作 |
| 草稿卡 | 魚種、總重、尾數、處理、售價（每台斤／整批／自動計算）、照片 | 確認發布、修改草稿、取消上架 | 🟡 新的售價與修改流程未實作 |
| 行情卡 | 平均價、當地縣市近 7／30 個交易日走勢、期間最高／最低、縣市或全國平均、交易日期、來源、養殖價格、參考整批金額、新鮮批發參考 | 無動作按鈕（走勢可切 7／30）；使用者直接回覆售價 | 🟡 後端已提供 `include=history`；卡片未實作（#29） |
| 法規告知卡 | 漁業法與證照提醒、罰則、法規連結 | 我已了解並確認、取消 | ⬜ |
| 訂單卡 | 品項數、總尾數、小計 | 展開明細、送出協議 | ✅ 以交易房上方的訂單摘要呈現，不另寫訊息卡 |
| 協議卡 | 整單金額、地點、時間、狀態 | 同意、退回、取消（選原因） | ✅ |
| 評價卡 | 星等、標籤、評語 | 送出；已評價後顯示等待對方或雙方完成 | ✅ |

未實作的卡片型別目前會退化成一行純文字，**不得**在畫面上出現「訊息卡片」這種預設字樣（目標）。

## 4. 顯示規則

| 規則 | 內容 |
| --- | --- |
| 價格 | 一律「元」，千分位；上架整批、每台斤、每尾均價、行情均價、成交價都要標明；自動計算的整批標「自動計算」 |
| 重量 | 一律「公斤」，一位小數 |
| 行情 | 只顯示平均價（元／台斤）；同時顯示交易日期、來源、縣市或全國平均、養殖價格（若）；行情區標「新鮮批發參考」；走勢圖為當地縣市近 7／30 個交易日；不顯示上價／中價／下價 |
| 售價與成交 | 上架售價是釣客開價；成交價是協議金額；兩者可以不同，不得混用 |
| 時間 | 訊息顯示相對時間或 `MM/DD HH:mm` |
| 商品標題 | `{魚種}（{總重}kg / {尾數}尾 / {處理}）` |
| 狀態用語 | 可售 N 尾／已售出／洽談中／等待確認／協商中／已成交／已取消 |
| 禁用詞 | 現流、野生、頂級、職人、大豐收、極鮮、超值、尚青；也不得把批發均價寫成「市價」 |
| 查無 | 「暫無行情」「暫時無法取得行情」「目前沒有符合條件的商品」，不得留空或填 0 |

## 5. 空狀態與失敗狀態

| 情境 | 顯示 |
| --- | --- |
| 沒有對話 | 「目前沒有對話。」 |
| 沒有 AI 對話 | 「目前沒有 AI 對話。按「新增 AI 對話」開始。」 |
| 查無商品 | 「沒有符合條件的今日漁獲，請調整篩選條件或地區。」 |
| 查無行情 | 「暫無行情」＋（可選）最近一次有資料的日期 |
| 行情上游失敗 | 「暫時無法取得行情。」 |
| 取消上架 | 「確定取消上架？此對話會一併刪除。」 |
| 刪除聊天室 | 「確定刪除聊天室？」 |
| 未登入 | 登入引導按鈕 |
| 後端未啟動 | 提示「無法連線到伺服器，請確認後端已啟動」，不得靜默失敗 |

## 6. 無障礙與互動細節

- 面板使用 `aria-live="polite"`，新訊息會被打字機唸出。
- 浮動按鈕有 `aria-expanded`、`aria-controls`、`aria-label`。
- 所有圖示按鈕都有 `title` 與 `aria-label`。
- 開啟面板時焦點移到輸入框；`Esc` 關閉。
- 交易房的電話號碼要可以點擊撥號（`tel:`），不遮蔽。
- 法規告知的「漁業法」連結另開新視窗，有可讀的連結文字與 focus 樣式；卡片的確認／取消按鈕要有 `aria-label`。

## 7. 響應式

| 寬度 | 行為 |
| --- | --- |
| > 760px | 面板固定右下角，寬度依公式，不遮住主要內容 |
| ≤ 760px | 面板全螢幕，浮動按鈕仍在右下 |

## 8. 文案範例

| 情境 | 好 | 壞 |
| --- | --- | --- |
| 上架追問 | 「請依序告訴我：重量（公斤或台斤）、尾數、處理方式（例如活體、放血冰鎮，也可以直接描述）、照片。可以一次全部輸入。」 | 「請輸入重量」（一次只問一個） |
| 行情卡 | 「現在花枝的行情是 31.4 元／台斤（2026-10-22，高雄市平均，農業部漁產品交易行情；近 7 個交易日 30.1–31.4）。參考整批約 157 元。請問要販賣多少錢？（可回覆每台斤價格或整批價格）」 | 「花枝大約 700 元，你要賣多少？」 |
| 養殖價格 | 「現在海鱸的行情是 123.4 元／台斤（養殖價格，2026-10-22，高雄市平均）。」 | 「海鱸行情 123.4 元」（沒有養殖標記） |
| 只填每台斤 | 「整批售價（自動計算）：157 元」 | 「157 元」（沒有說是不是自動計算） |
| 查無商品 | 「目前沒有符合條件的商品，可以換個魚種或地區再試。」 | 「查無資料」 |
| 查無行情 | 「目前沒有花枝的行情。請問要販賣多少錢？」 | 「花枝大約 700 元」 |
| 行情上游失敗 | 「暫時無法取得花枝的行情。請問要販賣多少錢？」 | 「暫無行情」（其實是查不到） |
| 修改草稿 | 「請問要修改哪個選項？」 | 「重新填寫」 |
| 取消上架 | 「確定取消上架？此對話會一併刪除。」 | 「已取消」 |
| 刪除聊天室 | 「確定刪除聊天室？」 | 直接刪除 |
| 第一次販賣 | 「販賣魚貨前，請先確認相關法規。」＋法規告知卡 | 直接進入上架欄位 |
| 法規告知卡 | 「販賣魚貨（一支釣）需依照法規申請相關合法證照；未申請可依法開罰新臺幣三萬元以上三十萬元以下罰鍰。參考：漁業法」 | 「本平台不負責」或沒有連結 |
| 法規確認後 | 「已確認，請依序告訴我：重量、尾數、處理方式、照片。」 | 又問一次法規 |
| 法規取消 | 「未確認，暫停販賣功能。想賣魚時再重新確認。」 | 直接開始上架 |
| 成交 | 「雙方都同意了，這筆交易成立。」 | 「下單成功！」 |
| 逾期 | 「協議已逾時未回覆，保留的數量已釋放。」 | 「訂單失敗」 |
