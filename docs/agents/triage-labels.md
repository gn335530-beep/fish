# Triage 標籤

技能以五個標準 triage 角色溝通。這個檔案把角色對照到本 repo issue tracker 實際使用的標籤字串。

| 標準角色 | 本 repo 的標籤 | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 維護者需要評估這個 issue |
| `needs-info` | `needs-info` | 等待回報者提供更多資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交給 agent 自主執行 |
| `ready-for-human` | `ready-for-human` | 需要人工實作 |
| `wontfix` | `wontfix` | 不處理 |

當技能提到某個角色（例如「套用 AFK-ready triage 標籤」），使用對照表中的標籤字串。

要改 vocabulary 時，直接編輯「本 repo 的標籤」欄。
