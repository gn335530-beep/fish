上架簡化與驗證報告

賣家上架頁刪除長度欄位並將「設定定價」移至市場行情正下方；恢復右上角人頭符號並顯示登入狀態；個人資訊新增頭像上傳、電話號碼改為反灰唯讀；刪除設計系統頁面。驗證日期：2026-10-09。

一、結論摘要

本次依需求將上架流程簡化為「三項必填、其餘選填」，完全移除長度欄位，並把設定定價上移至市場行情正下方；同時恢復右上角人頭符號（未登入顯示人頭＋登入／註冊，已登入顯示頭像＋暱稱），保留三條線選單作為個人資訊／賣家資訊／聊聊／登出的入口。

二、修改內容

1. 賣家上架頁：刪除長度欄位、調整欄位順序

  • 刪除「約幾公分長（cm）」欄位：HTML 輸入框、tailRows 的 len 資料、驗證訊息（.tail-len-err）全部移除；validate() 只檢查重量。
  • 上架只需三項重點：販售尾數、平均重量（可選擇改為各尾分別輸入）、價格；其餘（處理方式／備註／照片／地區地址／運送付款／定金）皆為選填。
  • 調整後順序：01 魚種與市場行情 → 02 設定定價 → 03 販售尾數與重量 → 04 處理方式與照片 → 05 地區與地址 → 06 運送與付款。
  • 買家端（products.html、product-detail.html、cart.html）與共用腳本的 tailRange() 一併移除長度顯示，改為只顯示尾數與重量。

2. 右上角人頭符號恢復並顯示登入狀態

  • 未登入：顯示人頭線稿圖示 ＋「登入／註冊」，為 <a href="login.html">，點擊導向登入頁。
  • 已登入：顯示頭像（有上傳頭像則顯示圖片，否則顯示暱稱首字）＋ 暱稱，點擊展開三條線選單。
  • 三條線選單仍保留作為入口；新增 refreshNavAvatar()，於 renderAuthNav() 與 initUserMenu() 呼叫，登入／登出／上傳頭像後即時重繪。

3. 刪除設計系統頁面

  • 刪除 design-system.html。
  • 移除 6 頁導覽列與頁尾所有指向它的連結；全站 grep "design-system" = 0 筆。

4. 個人資訊：頭像上傳 ＋ 電話反灰唯讀

  • 新增頭像上傳：支援點擊選擇與拖放，僅接受 JPG / PNG / WEBP、單檔上限 5MB；上傳後即時預覽並同步更新右上角人頭，資料存於 localStorage（haisen_avatar_v1），跨頁與重新載入後保留。
  • 電話號碼改為反灰唯讀：由 <input> 改為 <div class="readonly-field">（淺灰底 #EDEAE3＋灰字），不可編輯、不可點擊輸入；validate() 只驗證暱稱。
